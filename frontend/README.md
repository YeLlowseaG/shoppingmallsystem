# B2B成人用品采购平台前端

## 技术栈

- Vue 3.3.x
- TypeScript
- Vite 5.x
- Element Plus 2.x
- Vue Router 4.x
- Pinia 2.x
- Axios
- Day.js
- ECharts

## 项目结构

```
frontend/
├── src/
│   ├── api/              # API接口定义
│   ├── assets/           # 静态资源
│   ├── components/       # 公共组件
│   ├── views/            # 页面组件
│   ├── stores/           # 状态管理
│   ├── router/           # 路由配置
│   ├── utils/            # 工具函数
│   ├── types/            # TypeScript类型定义
│   ├── styles/           # 样式文件
│   ├── App.vue           # 根组件
│   └── main.ts           # 入口文件
├── public/               # 公共文件
├── index.html            # HTML模板
├── vite.config.ts        # Vite配置
├── tsconfig.json         # TypeScript配置
└── package.json          # 项目配置
```

## 开发

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build

# 预览生产构建
npm run preview
```

## 环境要求

- Node.js >= 18.x
- npm >= 9.x
