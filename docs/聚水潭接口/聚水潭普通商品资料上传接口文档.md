# 普通商品资料上传/更新接口文档

## 接口概览

*   **接口地址**:
    *   正式环境: `https://openapi.jushuitan.com/open/jushuitan/itemsku/upload`
    *   测试环境: `https://dev-api.jushuitan.com/open/jushuitan/itemsku/upload`
*   **接口功能**: 普通商品资料上传或更新（旧版）。
*   **数据流向**: 外部系统 -> 聚水潭ERP。
*   **单次限制**: 每次请求最多上传 **200** 个商品。

### 关键说明与常见问题 (Q&A)
1.  **字段更新逻辑**：若字段传值为空，原有数据会被清空；不传递该字段，则原有数据保持不变。**建议方案**：仅传递需要更新的字段。
2.  **备用字段**：接口中的 `other_price_1` 至 `other_price_5`（价格）和 `other_1` 至 `other_10`（属性）可作为备用字段。这些字段的名称可以在ERP中自定义，如需修改请联系实施或客服。
3.  **更多问题**：请参考[普通商品API常见问题文档](https://openweb.jushuitan.com/qaCenter?groupId=12&cataId=15¤tPage=1&pageSize=20)。

## 公共请求参数

以下参数需包含在**所有请求**中。

| 参数名称 | 类型 | 是否必填 | 描述 |
| :--- | :--- | :--- | :--- |
| `app_key` | String | 是 | POP平台分配给应用的标识。 |
| `access_token` | String | 是 | 通过授权码获取的访问令牌。 |
| `timestamp` | Long | 是 | UNIX时间戳（秒），需与聚水潭服务器时间差在10分钟内。 |
| `charset` | String | 是 | 字符编码，固定为 `utf-8`。 |
| `version` | String | 是 | API版本号，固定传 `2`。 |
| `sign` | String | 是 | 数字签名。 |

## 业务请求参数 (`items` 列表)

请求体主要是一个 `items` 数组，内含待上传的商品对象。

| 参数名称 | 类型 | 是否必填 | 示例值 | 描述 |
| :--- | :--- | :--- | :--- | :--- |
| **`items`** | `array` | **是** | - | 商品列表。 |
| └─ `sku_id` | string | 是 | `001C0812` | 商品SKU编码（商品编码）。 |
| └─ `i_id` | string | 是 | `001C0812` | 商品款号。 |
| └─ `name` | string | 是 | `短袖112` | 商品名称。 |
| └─ `brand` | string | 否 | `NIKE12` | 品牌。 |
| └─ `item_type` | string | 否 | `成品` | **可更新**。商品属性，可选值：`成品`、`半成品`、`原材料`、`包材`。 |
| └─ `enabled` | integer | 否 | `-1` | **可更新**。是否启用。`-1`=禁用，`0`=备用，`1`=启用。默认值：1。 |
| └─ `s_price` | number | 否 | `100` | 标准售价。 |
| └─ `market_price` | number | 否 | `300` | 市场价。 |
| └─ `c_price` | number | 否 | - | 成本价。 |
| └─ `other_price_1` 至 `other_price_5` | number | 否 | - | 其他价格1-5（均**可更新**），字段名可在ERP自定义。 |
| └─ `properties_value` | string | 否 | `蓝色;XXL` | 商品属性值（如：颜色；尺码）。 |
| └─ `remark` | string | 否 | `123` | **可更新**。备注。 |
| └─ `short_name` | string | 否 | `短袖12` | 商品简称。 |
| └─ `stock_disabled` | boolean | 否 | `true` | **可更新**。是否禁止库存同步。`true`=禁止，`false`=允许。 |
| └─ `other_1` 至 `other_10` | string | 否 | `2.11` | 其他属性1-10（均**可更新**），字段名可在ERP自定义。 |
| └─ `sku_code` | string | 否 | `648125644612` | 商品条形码。 |
| └─ `other_code` | string | 否 | - | 辅助码，长度不超过500。 |
| └─ `supplier_name` | string | 否 | `供应商1` | 供应商名称。 |
| └─ `supplier_sku_id` | string | 否 | `sup_sku_id12` | 供应商SKU编码。 |
| └─ `supplier_i_id` | string | 否 | `sup_i_id12` | 供应商款号。 |
| └─ `weight` | number | 否 | `1.52` | 重量（kg）。 |
| └─ `l`, `w`, `h` | number | 否 | `1` | 长、宽、高（单位需在ERP中设定）。 |
| └─ `pic` | string | 否 | `1231` | 商品图片。 |
| └─ `pic_big` | string | 否 | `Pic_big1` | 商品大图。 |
| └─ `sku_pic` | string | 否 | `Sku_pic11` | SKU图片。 |
| └─ `c_name` | string | 否 | - | 分类名称。 |
| └─ `vc_name` | string | 否 | `虚拟分类12` | 虚拟分类。 |
| └─ `unit` | string | 否 | - | 单位。 |
| └─ `labels` | `array` | 否 | - | 需要为商品**增加**的标签数组。 |
| └─ `deletedlabels` | `array` | 否 | - | 需要从商品**移除**的标签数组。 |
| └─ `CategoryPropertys` | `object` | 否 | - | 自定义分类属性键值对。 |
| └─ `shelf_life` | integer | 否 | `10` | 保质期天数，必须大于0。 |
| └─ `hand_day` | integer | 否 | `180` | 临期天数。 |
| └─ `batch_enabled` | boolean | 否 | `true` | 是否启用批次管理。 |
| └─ `is_series_number` | boolean | 否 | `true` | 是否为序列号管理。 |
| └─ `rejectLifecycle` | integer | 否 | `10` | 保质期禁收天数。 |
| └─ `lockupLifecycle` | integer | 否 | `20` | 保质期禁售天数。 |
| └─ `adventLifecycle` | integer | 否 | `30` | 保质期临期预警天数。 |
| └─ `production_licence` | string | 否 | `SC001` | 生产许可证编号。 |
| └─ `purchase_price` | number | 否 | - | 采购价。 |
| └─ `is_normal` | boolean | 否 | - | 默认为`false`。为`true`时，会校验修改的SKU类型不得为组合装，否则报错跳过。 |

## 返回参数说明

| 参数路径 | 类型 | 示例值 | 说明 |
| :--- | :--- | :--- | :--- |
| `code` | integer | `0` | 错误码。`0` 表示成功。 |
| `msg` | string | `执行成功` | 错误描述。 |
| `data` | object | - | 响应数据主体。 |
| `data.datas` | `array` | - | 每个商品的处理结果数组。 |
| `data.datas[].is_success` | string/boolean | `true` | 该商品是否上传成功。 |
| `data.datas[].sku_id` | string | `WL0400043` | 对应的商品编码。 |
| `data.datas[].msg` | string | `上传/更新成功` | 该商品的处理详情信息。 |

---

## 错误码与排查

| 错误码 | 错误信息 | 排查方法 |
| :--- | :--- | :--- |
| 130 | `分类【xxxxx】不存在，请修改分类或者重新维护【商品类目管理】` | 在ERP的【商品类目管理】页面维护对应的类目。 |
| 130 | `处理款(xxxxx)时发生错误:Arithmetic overflow error converting numeric to data type numeric` | 检查 `market_price` 字段数值是否过大或格式错误。 |
| 130 | `sku_id 必填且非空` | 检查 `items` 列表中的 `sku_id` 字段是否有空值。 |
| 120 | `验证失败!无效签名` | 检查签名 (`sign`) 的生成算法是否正确。 |
