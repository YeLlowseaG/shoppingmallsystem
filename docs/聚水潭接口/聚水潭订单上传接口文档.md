# 聚水潭订单上传接口文档

## 接口概览

*   **接口功能**：上传或更新商家自有商城、跨境线下、B2B的订单（**不支持代发订单**）。
*   **请求地址**：
    *   正式环境：`https://openapi.jushuitan.com/open/jushuitan/orders/upload`
    *   测试环境：`https://dev-api.jushuitan.com/open/jushuitan/orders/upload`
*   **单次限制**：每次请求最多上传 **50** 个订单。
*   **更新逻辑**：根据 `shop_id` + `so_id` 判断是否为同一订单。在订单发货前，可对文档中标记为 **“可更新”** 的字段进行更新。
*   **更多问题**：请参考 [订单API常见问题](https://openweb.jushuitan.com/qaCenter?groupId=12&cataId=17¤tPage=1&pageSize=20)。

## 核心说明与业务规则

### 1. 订单状态与支付节点
*   当订单状态 (`shop_status`) 为 `WAIT_BUYER_PAY`（等待买家付款）时，请求报文**不得**包含 `pay`（支付信息）节点。
*   除 `WAIT_BUYER_PAY` 外的所有其他状态，**必须**携带 `pay` 节点。
*   上传后，订单在ERP内可能显示为 **【异常（等待订单合并）】** ，这是针对同一买家的多订单合并场景，可直接转为正常单，无需特殊处理。

### 2. 金额计算逻辑
1.  **商品成交总额** = Σ(商品`price` * `qty`)。
2.  **应付总金额 (`pay_amount`)** = 商品成交总额 - 优惠金额 + 运费 (`freight`)。
    *   *优惠金额由系统根据 `商品成交总额 ≥ 应付金额` 的规则自动计算得出。*
3.  **实付金额** = `pay` 节点下 `amount` 的总和。
4.  **重要提示**：若订单中包含已退款成功的商品，**应付金额 (`pay_amount`)** 和**实付金额 (`pay.amount`)** 应上传原始金额，无需扣除退款部分。

### 3. 密文信息处理（来自电商平台的订单）
若订单从淘宝、抖音等平台获取，收件人信息为密文，上传时必须遵守以下规则：
*   **必填密文字段**：`full_receive_en_json`、`receiver_name_en`、`receiver_mobile_en`、`receiver_address`。
*   **平台标签**：必须在 `labels` 字段为订单打上对应的平台标签，如 **“抖音订单”**。
*   **格式说明**：
    *   `full_receive_en_json`：传入平台提供的**完整原始密文JSON串**。
    *   `receiver_name_en`、`receiver_mobile_en`、`receiver_address`：格式为 `平台编码:密文`。例如，抖音订单的姓名字段传 `147:****`。
*   **常用平台编码**：拼多多`050`， 淘宝`1`， 京东`-003`， 快手`209`， 抖音`147`。

## 公共请求参数

所有请求均需携带以下参数。

| 参数名称 | 类型 | 是否必填 | 描述 |
| :--- | :--- | :--- | :--- |
| `app_key` | String | 是 | POP平台分配给应用的唯一标识。 |
| `access_token` | String | 是 | 通过授权码获取的访问令牌。 |
| `timestamp` | Long | 是 | UNIX时间戳（单位：秒），与聚水潭服务器时间差须在10分钟内。 |
| `charset` | String | 是 | 字符编码，固定值 `utf-8`。 |
| `version` | String | 是 | API版本，固定传 `2`。 |
| `sign` | String | 是 | 数字签名。 |

### 支付信息 (`pay`)

当 `shop_status` 不为 `WAIT_BUYER_PAY` 时，此节点**必填**。

| 参数名 | 类型 | 必填 | 示例 | 描述 |
| :--- | :--- | :--- | :--- | :--- |
| `outer_pay_id` | string | 是 | `155775985878733471` | 外部支付单号（最大长度50）。 |
| `amount` | number | 是 | `706.0` | **支付总额**（元，保留两位小数），应与各支付方式金额总和一致。 |
| `pay_date` | string | 是 | `2019-12-16 16:35:28` | 支付完成日期。 |
| `payment` | string | 是 | `微信` | 支付方式（最大长度20）。 |
| `seller_account` | string | 是 | `未知` | 收款账户（最大长度50）。 |
| `buyer_account` | string | 是 | `38` | 买家支付账号（最大长度200）。 |

### 身份证信息 (`card`)

此节点非必填，但如果填写了其中任意字段，则 `name` 和 `card_id` 都**必填**。

| 参数名 | 类型 | 必填 | 示例 | 描述 |
| :--- | :--- | :--- | :--- | :--- |
| `name` | string | 条件必填 | `11` | 身份证姓名（**可更新**）。 |
| `card_id` | string | 条件必填 | `11` | 身份证号码（**可更新**）。 |
