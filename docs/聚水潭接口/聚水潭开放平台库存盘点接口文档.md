# 聚水潭开放平台库存盘点接口文档

## 接口概述
**接口名称**：库存盘点-修改库存
**系统界面**：【库存】→【库存盘点】
**接口地址**：
- **正式环境**：`https://openapi.jushuitan.com/open/jushuitan/inventoryv2/upload`
- **测试环境**：`https://dev-api.jushuitan.com/open/jushuitan/inventoryv2/upload`

**核心功能**：用于创建库存盘点单，以修改系统中的商品库存数量。

## 重要说明与注意点
1.  **分仓编码查询**：可通过 [相关接口](https://open.jushuitan.com/document/2064.html) 查询 `wms_co_id`（仓库编码）。
2.  **无变动不创建**：若盘点数量与原库存无差异，则不会生成盘点记录。
3.  **批次号格式**：`batch_id` 字段支持 `/`、`@`、`.`、`-`、汉字等特殊字符。
4.  **更多问题**：库存API的常见问题可查阅 [官方QA文档](https://openweb.jushuitan.com/qaCenter?groupId=12&cataId=16¤tPage=1&pageSize=20)。

## 公共请求参数
所有请求必须包含以下公共参数：

| 参数名 | 类型 | 是否必填 | 描述 |
| :--- | :--- | :--- | :--- |
| `app_key` | String | 是 | POP平台分配给应用的唯一标识。 |
| `access_token` | String | 是 | 通过授权码获取的访问令牌。 |
| `timestamp` | Long | 是 | UNIX时间戳（秒），与服务器时间差需在10分钟内。 |
| `charset` | String | 是 | 字符编码，固定值：`utf-8`。 |
| `version` | String | 是 | API版本号，固定值：`2`。 |
| `sign` | String | 是 | 数字签名。 |

## 业务请求参数
请求体为JSON格式，主要参数如下：

| 参数名 | 类型 | 是否必填 | 示例值 | 参数描述 |
| :--- | :--- | :--- | :--- | :--- |
| `so_id` | String | **是** | `20220617` | **外部单号**，用于唯一标识此次盘点请求。 |
| `warehouse` | String | **是** | `1` | **仓库类型**。主仓=`1`，销退仓=`2`，进货仓=`3`，次品仓=`4`，自定义1仓=`6`，自定义2仓=`7`，自定义3仓=`8`。 |
| `items` | Array | **是** | - | **商品明细列表**，单次最大支持 **500** 条。 |
| `type` | String | 否 | `check` | **盘点类型**。**非精细化盘点时**：`check`（全量盘点，覆盖传入商品库存）；`adjust`（增量盘点，在原库存上增减，此为**默认值**）。**开启精细仓位管理后**：`check`（全量盘点，仓位上未传的商品库存将被盘为0）；`adjust`（增量盘点，未传商品库存不变）。 |
| `wms_co_id` | Integer | 否 | `10158015` | 仓库编码。不填时默认操作主仓。 |
| `is_confirm` | Boolean | 否 | `false` | 是否自动确认单据，默认`false`（创建为草稿状态）。 |
| `remark` | String | 否 | | 备注信息。 |
| `bin` | String | 否 | `A-1-1` | **仓位**。当系统开启精细化管理时，此字段为**必填**。 |
| `default_type` | String | 否 | | **暂存位类型**。开启精细化管理时有效且必填。可选值：`Default`（暂存位），`Pick`（拣货暂存位），`None`。 |

### `items` 商品明细字段说明

| 字段名 | 类型 | 是否必填 | 示例值 | 描述 |
| :--- | :--- | :--- | :--- | :--- |
| `sku_id` | String | **是** | `001` | 聚水潭系统的商品规格ID。 |
| `qty` | Integer | **是** | `0` | **盘点数量**。 |
| `batch_id` | String | 否 | | 批次号。**若系统开启商品批次管理，则必填**。 |
| `sku_sns` | Array\<String\> | 否 | | **唯一码（序列号）集合**。**重要**：当 `type = adjust`（增量盘点）时，**不支持**传入此字段，否则会报错。 |
| `supplier_id` | Number | 否 | | 供应商编码。 |
| `produced_date` | String | 否 | | 生产日期。格式：`YYYY-MM-DD HH:mm:ss`，时间范围 `1970-01-01 00:00:00` 至 `3000-01-01 00:00:00`。 |
| `expiration_date` | String | 否 | | 有效期至。格式及范围同上。 |

## 返回参数说明
接口返回统一的JSON格式数据：

| 参数名 | 类型 | 示例值 | 说明 |
| :--- | :--- | :--- | :--- |
| `code` | Number | `0` | **状态码**，`0` 表示成功。 |
| `issuccess` | Boolean | `true` | **执行结果**，`true` 或 `false`。 |
| `msg` | String | `执行成功` | **结果描述信息**。 |
| `data` | Object | `{}` | 业务数据对象。 |
| `data.data` | Object | `{}` | 内部数据对象。 |
| `data.data.msg` | String | | 详细的执行消息。 |
| `data.data.so_id` | String | | 外部单号（即请求传入的 `so_id`）。 |
| `data.data.io_id` | Number | `0` | 系统生成的**盘点单号**。 |

## 错误码与排查方法

| 错误码 | 错误信息示例 | 排查方法 |
| :--- | :--- | :--- |
| 130 | "批次号格式不正确" | 检查 `batch_id`，仅支持 `/`、`@`、`.`、`-`、汉字等特殊字符。 |
| 130 | "已经开通了精细仓位库存管理，当前功能禁用…" | 系统已启用精确库存（仓位）管理，需使用手持模块或其他出入库接口操作库存。 |
| 140 | "验证失败！appkey无效" | **检查请求环境**：测试环境的 `app_key` 只能用于测试地址，正式环境同理。 |
| 150 | "内部异常：Transaction ... was deadlocked ..." | 前一次请求未执行完就发起新请求，导致死锁。请等待上一次调用完成后再试。 |
| 120 | "验证失败!无效签名" | 检查签名 (`sign`) 计算方式是否正确。 |
| 190 | "验证失败！无API权限，请申请API权限" | **需要申请API权限**：请前往聚水潭开放平台，在应用管理页面申请 `inventoryv2/upload`（库存盘点接口）的API权限。此接口权限需要单独申请，与商品资料上传接口权限不同。 |
