# 聚水潭开放平台订单取消接口文档

## 接口概述
**接口名称**：订单取消-按内部单号取消
**接口地址**：
- **正式环境**：`https://openapi.jushuitan.com/open/jushuitan/orderbyoid/cancel`
- **测试环境**：`https://dev-api.jushuitan.com/open/jushuitan/orderbyoid/cancel`

**核心功能**：根据聚水潭ERP系统的内部订单号(`o_id`)取消订单。

**重要状态限制**：
**仅处于以下状态的订单才能被取消**：
- 待付款
- 发货中
- 异常
- 已付款待审核
- 已审核待配快递
- 等供销商|外仓发货
- 等供销商发货
- 已客审待财审

## 公共请求参数
所有请求必须包含以下公共参数：

| 参数名 | 类型 | 是否必填 | 描述 |
| :--- | :--- | :--- | :--- |
| `app_key` | String | 是 | POP平台分配给应用的唯一标识。 |
| `access_token` | String | 是 | 通过授权码获取的访问令牌。 |
| `timestamp` | Long | 是 | UNIX时间戳（秒），与服务器时间差需在10分钟内。 |
| `charset` | String | 是 | 字符编码，固定值：`utf-8`。 |
| `version` | String | 是 | API版本号，固定值：`2`。 |
| `sign` | String | 是 | 数字签名。 |

## 业务请求参数
请求体为JSON格式，主要参数如下：

| 参数名 | 类型 | 是否必填 | 示例值 | 描述 |
| :--- | :--- | :--- | :--- | :--- |
| `o_ids` | Array\<Integer\> | **是** | `[111]` | 需要取消的订单对应的**内部单号** (`o_id`) 数组。 |
| `cancel_type` | String | **是** | `不需要了` | 取消订单的原因或类型。 |
| `remark` | String | 否 | | 取消订单的备注信息。 |

## 返回参数说明
接口返回统一的JSON格式数据：

| 参数名 | 类型 | 示例值 | 说明 |
| :--- | :--- | :--- | :--- |
| `code` | Integer | `0` | **错误码**，`0`表示成功。 |
| `msg` | String | `执行成功` | **结果描述信息**。 |
| `data` | Object | `""` | 业务数据对象，成功时通常为空字符串。 |

## 错误码与排查方法

| 错误码 | 错误信息示例 | 排查方法 |
| :--- | :--- | :--- |
| 130 | `执行失败订单[112234] 该状态不允许取消` | 检查订单在ERP中的当前状态，确认其是否符合API说明中列出的“可取消”状态。 |
| 120 | `验证失败!无效签名` | 检查签名(`sign`)计算方式是否正确。 |

## 请求示例
```json
{
  "o_ids": [111, 112],
  "remark": "买家主动取消",
  "cancel_type": "不需要了"
}

响应示例
成功响应
json
{
  "msg": "执行成功",
  "code": 0,
  "data": ""
}
异常响应示例
json
{
  "code": 120,
  "msg": "验证失败!无效签名"
}
温馨提示：调用前请务必确认目标订单的当前状态，处于“已发货”、“已完成”等状态的订单无法通过此接口取消。
