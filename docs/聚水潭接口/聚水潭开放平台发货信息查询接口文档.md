# 聚水潭开放平台发货信息查询接口文档

## 接口概述
**接口名称**：发货信息查询
**接口地址**：
- **正式环境**：`https://openapi.jushuitan.com/open/logistic/query`
- **测试环境**：`https://dev-api.jushuitan.com/open/logistic/query`

**核心功能**：用于查询订单的发货物流信息。
**重要说明**：此接口的返回数据**不包含淘系、拼多多等平台的敏感数据（如线上单号）**。

## 公共请求参数
所有请求必须包含以下公共参数：

| 参数名 | 类型 | 是否必填 | 描述 |
| :--- | :--- | :--- | :--- |
| `app_key` | String | 是 | POP平台分配给应用的唯一标识。 |
| `access_token` | String | 是 | 通过授权码获取的访问令牌。 |
| `timestamp` | Long | 是 | UNIX时间戳（秒），与服务器时间差需在10分钟内。 |
| `charset` | String | 是 | 字符编码，固定值：`utf-8`。 |
| `version` | String | 是 | API版本号，固定值：`2`。 |
| `sign` | String | 是 | 数字签名。 |

## 业务请求参数
请求体为JSON格式，支持按多种条件筛选和分页查询：

| 参数名 | 类型 | 是否必填 | 示例值 | 描述 |
| :--- | :--- | :--- | :--- | :--- |
| `shop_id` | Integer | 否 | `10191811` | 店铺编号，用于筛选特定店铺的订单。 |
| `page_index` | Integer | 否 | `1` | **页码**，从 **1** 开始计数。不传默认为1。 |
| `page_size` | Integer | 否 | `30` | **每页记录数**。默认30条，**最大不超过50条**。 |
| `modified_begin` | String | 否 | `2021-12-02 15:55:06` | **时间筛选的起始点**。必须与 `modified_end` 成对出现，且时间间隔**不能超过7天**。格式：`YYYY-MM-DD HH:mm:ss`。 |
| `modified_end` | String | 否 | `2021-12-09 15:55:06` | **时间筛选的结束点**。必须与 `modified_begin` 成对出现。 |
| `date_type` | Integer | 否 | `0` | **日期类型**，决定以上时间范围针对哪个字段。可选值：`0`=修改时间，`1`=制单日期，`2`=订单日期，`3`=发货时间。**默认按发货时间(`3`)**查询。 |
| `so_ids` | Array\<String\> | 否 | `["order1", "order2"]` | **平台订单号数组**。用于批量查询指定订单号的发货信息。 |

## 返回参数说明
接口返回分页格式的JSON数据：

| 参数名 | 类型 | 示例值 | 说明 |
| :--- | :--- | :--- | :--- |
| `code` | Integer | `0` | **错误码**，`0`表示成功。 |
| `msg` | String | `执行成功` | **结果描述信息**。 |
| `data` | Object | `{}` | 业务数据主体。 |
| `data.page_size` | Integer | `2` | **每页条数**，同请求参数。 |
| `data.page_index` | Integer | `1` | **当前页码**，同请求参数。 |
| `data.data_count` | Integer | `2` | **符合条件的数据总条数**。 |
| `data.page_count` | Integer | `1` | **总页数**。 |
| `data.has_next` | Boolean | `false` | **是否有下一页**。 |
| `data.orders` | Array\<Object\> | `[]` | **订单数据列表**。 |

### `orders` 数组中每个订单对象的字段说明

| 字段名 | 类型 | 示例值 | 说明 |
| :--- | :--- | :--- | :--- |
| `o_id` | Integer | `3090086` | **ERP内部订单号**，唯一标识。 |
| `shop_id` | Integer | `14588` | **店铺编号**。 |
| `so_id` | String | `8-m2` | **平台订单号**，最长50字符，唯一。 |
| `as_id` | Number | | 如果是补发或换货订单，此字段为对应的**售后单号**。 |
| `send_date` | String | `2019-12-16 18:18:34` | **发货时间**。 |
| `freight` | Number | `8.0` | **运费**。 |
| `weight` | Number | `0.0` | **包裹重量**。 |
| `wms_co_id` | Number | `0` | **发货仓编码**，`0` 表示主仓发货。 |
| `lc_id` | String | `April` | **快递公司代码**。 |
| `l_id` | String | `765433222222` | **快递单号**。 |
| `logistics_company` | String | `申通快递` | **快递公司名称**。 |
| `items` | Array\<Object\> | `[]` | **订单商品明细列表**。 |

### `items` 商品明细字段说明

| 字段名 | 类型 | 示例值 | 说明 |
| :--- | :--- | :--- | :--- |
| `sku_id` | String | `s111001` | **商家SKU编码**，对应库存管理的规格ID。 |
| `qty` | Integer | `1` | **购买数量**。 |
| `outer_oi_id` | String | `1216001` | **平台子订单号**。 |
| `raw_so_id` | String | `8-m1` | **原始平台订单号**，可能为空。 |
| `o_id` | String | `3090086` | **内部单号**（与顶层`o_id`一致）。 |
| `refund_status` | String | | **商品退款状态**。 |
| `sku_type` | String | | **商品类型**。 |

## 错误说明
文档中暂未列出具体的业务错误码。常见的签名错误如下：

| 错误码 | 错误信息 | 排查方法 |
| :--- | :--- | :--- |
| 120 | `验证失败!无效签名` | 检查签名(`sign`)计算方式是否正确。 |
