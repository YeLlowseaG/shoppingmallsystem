# 聚水潭开放平台店铺商品资料上传接口文档

## 接口概述
**接口名称**：店铺商品资料上传  
**接口地址**：  
- 正式环境：`https://openapi.jushuitan.com/open/jushuitan/skumap/upload`  
- 测试环境：`https://dev-api.jushuitan.com/open/jushuitan/skumap/upload`

**功能说明**：用于创建或更新店铺商品资料信息（商品链接），主要服务于商品库存推送功能。  
**注意事项**：
- 单次请求最多可上传 **50** 个商品
- 目标店铺的站点类型必须为 **"商家自有商城"**，否则会报错

## 公共请求参数
所有请求必须包含以下公共参数：

| 参数名 | 类型 | 是否必填 | 描述 |
|--------|------|----------|------|
| app_key | String | 是 | POP平台分配给应用的唯一标识 |
| access_token | String | 是 | 通过授权码获取的访问令牌 |
| timestamp | Long | 是 | UNIX时间戳（秒），与服务器时间差需在10分钟内 |
| charset | String | 是 | 字符编码，固定值：`utf-8` |
| version | String | 是 | API版本号，固定值：`2` |
| sign | String | 是 | 数字签名 |

## 业务请求参数
请求体为JSON格式，包含以下参数：

| 参数名 | 类型 | 是否必填 | 示例值 | 描述 |
|--------|------|----------|--------|------|
| items | Array | 是 | - | 商品信息列表 |

### items数组中每个对象的字段说明

| 字段名 | 类型 | 是否必填 | 示例值 | 描述 |
|--------|------|----------|--------|------|
| shop_id | Integer | 是 | 10192724 | 聚水潭系统中的店铺编号 |
| sku_id | String | 是 | S01 | 聚水潭商品规格ID（ERP系统内） |
| shop_sku_id | String | 是 | S01 | 线上店铺商品规格ID（店铺平台中） |
| shop_i_id | String | 是 | I01 | 线上店铺商品ID（店铺平台中） |
| i_id | String | 否 | I01 | 聚水潭商品ID（ERP系统内） |
| sku_code | String | 否 | 135489 | 商品编码 |
| original_sku_id | String | 否 | O01 | 原始规格ID |
| name | String | 否 | 耳机 | 商品名称（可更新） |
| shop_properties_value | String | 否 | 蓝色;XL | 店铺颜色规格（可更新） |
| sku_sign | String | 否 | `""` | 商品标识（如零售、阶梯等，可更新，可为空字符串） |
| shop_sku_url | String | 否 | - | 商品线上链接 |

## 返回参数
接口返回统一JSON格式数据：

| 参数名 | 类型 | 示例值 | 说明 |
|--------|------|--------|------|
| code | Integer | 0 | 错误码，0表示成功 |
| msg | String | 执行成功 | 错误描述信息 |
| data | Object | {} | 业务数据对象，成功时通常为空 |

## 错误码说明
| 错误码 | 错误信息 | 排查方法 |
|--------|----------|----------|
| 170 | 店铺编号[123] 不是公司[456]的店铺 | 调用店铺查询接口确认shop_id是否存在 |
| 120 | 验证失败!无效签名 | 检查签名计算方式 |
| - | 店铺编号[xxx]的站点类型不是自有商城，无法上传 | 检查店铺设置，确保站点类型为"商家自有商城" |

常见问题
Q: 接口一次最大可以上传多少个商品？
A: 接口每次请求最大50个商品。

Q: 错误返回"店铺编号[xxx]的站点类型不是自有商城，无法上传"怎么办？
A: 需要在【店铺设置】里新增店铺，站点选择"商家自有商城"。

Q: 为什么需要对接这个接口？
A: 该接口主要用于创建店铺商品资料信息，实现商品库存推送功能。
