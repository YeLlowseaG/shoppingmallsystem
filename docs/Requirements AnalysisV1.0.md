## 1. 系统概述

### 1.1 系统定位
B2B成人用品采购平台，平台直接管理商品，为采购者提供商品展示、订单管理、采购结算等一站式服务。

### 1.2 核心价值
- **采购者端**: 获取优质货源，享受批发价格，便捷下单
- **平台端**: 统一管理商品和库存，处理订单发货，提供交易保障，数据支持，运营服务

### **1.3主要业务流程**

1\. 用户注册流程（采购者入驻）

采购者注册 → 填写基本信息 → 手机/邮箱验证 → 签署分销协议

→ 注册成功 → 账户自动激活 → 可以采购

**涉及角色**：采购者

\-\--

2\. 商品发布流程（平台管理商品）

平台管理员登录后台 → 商品管理 → 发布商品 → 填写商品信息

→ 上传图片 → 设置价格和库存 → 设置分类和标签 → 保存并上架

→ 商品在前端展示 → 采购者可见

**涉及角色**：平台管理员

\-\--

3\. 采购下单流程（核心流程）

采购者浏览商品 → 选择商品 → 加入购物车 / 立即购买

→ 进入结算页 → 选择收货地址 → 确认订单信息 → 选择支付方式

→ 提交订单 → 进行支付 → 支付成功 → 订单生成

→ 平台收到订单通知

**涉及角色**：采购者

\-\--

4\. 订单处理流程（履约流程）

平台管理员收到订单 → 查看订单详情 → 确认订单 → 准备商品

→ 填写物流信息 → 发货 → 更新订单状态为\"已发货\"

→ 采购者收到发货通知 → 查询物流 → 商品送达

→ 采购者确认收货 → 订单完成

**涉及角色**：平台管理员、采购者

\-\--

5\. 支付结算流程

采购者提交订单 → 选择支付方式（在线/线下）

→ 完成支付 → 支付回调 → 订单状态更新为\"待发货\"

→ 平台发货 → 订单完成 → 结算完成

**涉及角色**：采购者、平台管理员

\-\--

**扩展流程**

6\. 预存款充值流程

采购者进入会员中心 → 我的预存款 → 申请充值

→ 选择充值金额 → 选择充值方式 → 上传支付凭证

→ 提交充值申请 → 平台管理员审核 → 审核通过

→ 预存款到账 → 可用于支付订单

\-\--

7\. 订单取消/退款流程

【未付款订单取消】

采购者查看订单 → 点击取消订单 → 订单状态变为\"已取消\"

【已付款退款】

采购者联系客服 → 平台管理员在后台处理退款

→ 退款操作 → 订单状态变为\"已退款\"

\-\--

8\. 售后处理流程

采购者收到商品有问题 → 提交售后申请（退货/换货）

→ 平台管理员审核 → 审核通过 → 采购者寄回商品

→ 平台收到退货 → 处理退款/换货 → 售后完成

\-\--

9\. 商品收藏/缺货登记流程

【收藏流程】

采购者浏览商品 → 点击收藏 → 商品添加到收藏夹

→ 可在会员中心快速查看和下单

【缺货登记】

采购者发现商品缺货 → 登记缺货 → 商品到货

→ 系统通知采购者 → 采购者采购

\-\--

10\. 订单批量上传流程

采购者准备订单数据（Excel/CSV）→ 进入会员中心

→ 订单批量上传 → 上传文件 → 系统解析订单

→ 订单导入成功 → 已导入订单列表 → 批量支付/处理

\-\--

## 2. 用户角色与权限体系

### 2.1 用户角色定义

#### 2.1.1 采购者（Buyer）
- **角色描述**: 商品采购方，从平台采购商品
- **核心权限**:
  - 浏览商品目录
  - 下单采购
  - 订单查询与跟踪
  - 账户余额管理
  - 个人信息管理
  - 收货地址管理

#### 2.1.2 平台管理员（Admin）
- **角色描述**: 平台运营方，管理系统整体运营，直接管理商品和订单
- **核心权限**:
  - 商品信息管理（发布、编辑、下架）
  - 库存管理
  - 订单处理与发货
  - 采购者管理
  - 采购者等级管理
  - 会员积分管理
  - 会员等级折扣配置
  - 积分奖励规则配置
  - 价格策略设置
  - 促销活动创建与管理
  - 系统配置
  - 数据统计分析
  - 管理员用户管理
  - 角色权限管理
  - 菜单权限管理

#### 2.1.3 管理员权限体系（RBAC）
- **权限模型**: 基于角色的访问控制（Role-Based Access Control）
- **权限组成**:
  - **用户（Admin User）**: 管理员账户，可分配多个角色
  - **角色（Role）**: 权限集合，如：超级管理员、运营人员、客服人员等
  - **菜单（Menu）**: 系统功能菜单，包含权限标识
  - **权限标识（Permission）**: 细粒度权限控制，如：admin:user:list、admin:order:edit
- **权限分配流程**:
  1. 创建角色并分配菜单权限
  2. 创建管理员用户并分配角色
  3. 管理员登录后根据角色动态加载菜单
  4. 前端路由和后端接口根据权限标识进行权限控制

### 2.2 采购者等级体系（基于积分）
- **等级划分**: 根据会员积分自动划分等级，积分越高等级越高
- **等级配置**: 后台可配置积分区间对应的等级名称和折扣率
- **等级权益**:
  - 不同等级享受不同的商品折扣
  - 等级越高，折扣越大
  - 等级自动升级（达到积分要求后自动升级）
- **积分获取**: 通过订单消费获得积分（订单已发货后获得）

## 3. 核心功能模块

### 3.1 用户管理模块

#### 3.1.1 注册与认证
- **会员注册协议**
  - 协议内容展示
  - 协议阅读确认
  - 同意协议后跳转到注册表单
  
- **采购者注册表单**
  - **必填字段**
    - 用户名（唯一标识，用于登录）
    - 电子邮箱（用于接收通知和找回密码）
    - 密码（登录凭证）
    - 确认密码（二次确认）
    - 姓名（真实姓名）
    - 性别（单选：男/女）
    - 地区（三级联动下拉：省/市/区）
    - 联系地址（详细地址）
    - 移动电话（手机号码）
    - 运营人员（运营人员信息）
    - 验证码（防止机器人注册）
  - **可选字段**
    - 出生日期（年/月/日三个下拉选择）
    - 邮编（邮政编码）
    - 固定电话（座机号码）
    - 安全问题（用于找回密码）
    - 回答（安全问题答案）
    - 旺旺（旺旺账号）
  
  
- **注册流程**
  - 阅读并同意会员注册协议
  - 填写注册表单信息
  - 提交注册
  - 注册成功，账户自动激活
  - 可以立即登录使用

#### 3.1.2 登录与安全
- **账号密码登录**
  - 用户名输入（必填）
  - 密码输入（必填）
  - 立即登录按钮
  - 注册入口链接
  - 忘记密码入口链接

- **密码找回**
  - 忘记密码页面
    - 页面标题："忘记密码？"
    - 说明文字："如果忘记密码，请填写下面表单来重新获取密码"
    - 用户名输入（必填，带*号）
    - 提交按钮
  - 密码找回处理
    - 系统验证用户名是否存在
    - 如果用户不存在：显示错误提示"该用户不存在！"，10秒后自动跳转，也可点击直接跳转
    - 如果用户存在：发送密码重置信息到注册邮箱
  - 密码重置
    - 用户通过邮箱接收密码重置链接或新密码
    - 用户使用新密码登录或通过链接重置密码

- **登录安全**
  - 登录日志记录
  - 密码加密存储

#### 3.1.3 个人信息管理
- 基本信息修改
- 头像上传
- 登录密码修改
- 预存款支付密码修改
- 绑定手机/邮箱
- 实名认证
- 会员积分查看
- 会员等级查看
- 积分明细查询

### 3.2 商品管理模块

#### 3.2.1 商品分类体系
- **一级分类**: 按产品类型划分（如：情趣用品、健康护理、情趣内衣等）
- **二级分类**: 细分产品类别
- **三级分类**: 更细化的产品属性
- **标签管理**: 热门、新品、促销、限时等标签

#### 3.2.2 商品信息管理
- **基础信息**
  - 商品名称
  - 商品编码/SKU
  - 商品图片（主图、详情图、多角度展示）
  - 商品描述（文字、图文混排）
  - 规格参数（尺寸、材质、颜色、包装等）
  
- **价格管理**

  - 促销价格（限时特价）

- **库存管理**
  - 库存数量设置
  - 库存预警阈值
  - 库存实时更新
  - 库存锁定机制（下单锁定）

#### 3.2.3 商品展示功能
- **商品列表页**
  - 分类筛选
  - 价格排序（从低到高、从高到低）
  - 销量排序
  - 新品排序
  - 关键词搜索
  - 多条件组合筛选（价格区间、品牌、标签等）
  - 分页展示
  
- **商品详情页**
  - 商品图片轮播/放大
  - 商品基本信息展示
  - 价格展示（基础价格，根据会员等级自动计算折扣后价格）
  - 会员折扣提示（显示当前等级享受的折扣率）
  - 库存状态显示
  - 规格选择
  - 购买数量选择
  - 加入购物车
  - 立即下单
  - 商品评价/评分（可选）
  - 相关商品推荐

#### 3.2.5 采购者商品管理功能
- **商品更新列表**
  - 查看平台新上架商品
  - 商品更新信息提醒
  - 商品上架操作
  
- **商品活动查看**
  - 查看商品促销活动
  - 活动商品列表
  - 活动时间提醒

#### 3.2.6 商品收藏与缺货管理
- **商品收藏**
  - 收藏商品列表
  - 取消收藏
  - 收藏商品快速下单
  
- **缺货登记**
  - 登记缺货商品
  - 缺货商品列表
  - 到货通知

#### 3.2.7 商品留言与咨询
- **评论与咨询**
  - 商品评论查看
  - 商品咨询查看
  - 回复咨询（可选）

#### 3.2.4 商品管理机制
- 平台管理员直接发布商品
- 商品信息编辑与更新
- 商品上架/下架管理

### 3.3 购物车模块

  - 销售价格（原价）

  - 删除按钮（单个删除）

- **购物车操作功能**
  - 商品数量修改（输入框+上下箭头调整）

  - 商品总重量统计
  - 订单总计显示
  
- **购物流程进度条**
  - 显示购物流程步骤（查看购物车、用户登录或注册、填写购物信息、完成订单）
  - 当前步骤高亮显示
  
- **库存校验**
  - 下单时检查库存
  - 库存不足提示

#### 3.3.2 购物车数据
- 商品信息（图片、名称、规格、货号）
- 价格信息（销售价格、会员价、批发优惠价）
- 单价（根据用户等级显示对应价格）
- 数量
- 小计金额
- 商品重量
- 库存状态

### 3.4 订单管理模块

#### 3.4.1 下单流程
- 购物车结算
- 用户登录验证（如未登录，需先登录）
- 填写收货人信息
  - 选择已有收货地址或新增地址
  - 填写收货地区（省/市/区三级联动）
  - 填写街道地址
  - 填写邮编
  - 填写收货人姓名
  - 填写联系电话/联系手机
  - 选择是否保存地址
- 选择配送日期和时间
- 填写订单附言（订单备注）
- 选择配送方式
- 选择支付币别
- 选择支付方式
- 确认商品信息
- 确认订单金额明细（商品总价、运费、税金、订单总金额）
- 填写发票抬头（可选）
- 订单提交
- 订单生成（订单号、下单时间）

#### 3.4.2 订单状态管理
- **待付款**（等待付款）: 订单已创建，等待支付
- **已付款未发货**: 已付款，等待平台发货
- **待发货**: 已付款，等待平台发货（同已付款未发货）
- **已发货**: 平台已发货，物流中
- **已完成**: 订单已签收，交易完成
- **已取消**（已作废）: 订单取消（未付款可取消，已付款需申请）
- **已退款**: 订单退款完成
- **已退货**: 订单退货完成
- **部分发货**: 订单中部分商品已发货

#### 3.4.3 订单查询功能
- **采购者端**
  - **订单搜索/筛选**
    - 收货人姓名搜索（文本输入框）
    - 交易状态筛选（下拉选择：全部订单、等待付款、已付款未发货、已发货、已完成、已退款、已退货、已作废）
    - 查询订单按钮
  - **订单列表查看**
    - 订单状态标签页（全部订单、等待付款、已付款未发货、已发货、已完成、已退款、已退货、已作废）
    - 当前选中状态高亮显示
  - **订单列表表格**
    - 复选框（选择订单）
    - 订单号（订单编号）
    - 收货人信息（省份+收货人姓名）
    - 订单描述（商品描述+商品数量）

#### 4.2.10 管理后台菜单层级结构

管理后台菜单采用最多2层结构（一级目录 + 二级页面），菜单权限只到页面层级，具体结构如下：

```
管理后台菜单结构（最多2层）
├── 1. 首页（Dashboard）
│   └── 数据概览
│
├── 2. 商品管理
│   ├── 商品列表
│   ├── 商品发布
│   └── 商品分类
│
├── 3. 订单管理
│   └── 订单列表
│
├── 4. 库存管理
│   ├── 库存列表
│   ├── 库存预警
│   ├── 库存调整
│   └── 库存统计
│
├── 5. 采购者管理
│   ├── 采购者列表
│   ├── 积分管理
│   └── 等级管理
│
├── 6. 营销管理
│   ├── 促销活动
│   └── 价格策略
│
├── 7. 数据统计
│   ├── 销售统计
│   ├── 订单统计
│   ├── 商品统计
│   └── 采购者统计
│
├── 8. 系统设置（一级菜单）
│   ├── 基础配置
│   ├── 支付配置
│   ├── 物流配置
│   ├── 通知设置
│   ├── 会员等级折扣配置
│   └── 积分奖励规则配置
│
└── 9. 权限管理（一级菜单）
    ├── 用户管理
    ├── 角色管理
    └── 菜单管理
```

**菜单层级说明**：
- **一级菜单（目录）**：9个主要功能模块，包括系统设置和权限管理作为独立的一级菜单
- **二级菜单（页面）**：各模块下的具体功能页面
- **权限控制**：菜单权限只到页面层级，页面内的按钮操作权限由前端根据角色或用户权限进行控制

**角色权限说明**：
- **超级管理员（ADMIN）**：拥有所有菜单权限
- **运营人员（OPERATOR）**：拥有商品、订单、库存、采购者、营销、数据统计模块权限
- **客服人员（CUSTOMER_SERVICE）**：拥有订单、采购者管理模块权限
- **财务人员（FINANCE）**：拥有订单、数据统计模块权限

## 5. 业务流程

### 5.1 用户注册流程
1. 用户访问注册页面
2. 显示会员注册协议页面
3. 用户阅读会员注册协议内容
4. 用户点击"同意协议"按钮
5. 跳转到注册表单页面
6. 用户填写注册表单信息
   - 填写必填字段（用户名、邮箱、密码、姓名、性别、地区、联系地址、移动电话、运营人员等）
   - 填写可选字段（出生日期、邮编、固定电话、安全问题等）
   - 输入验证码
7. 用户点击"立即注册"按钮
8. 系统验证表单信息（字段格式、验证码等）
9. 提交注册
10. 注册成功，账户自动激活
11. 初始积分为0，等级为最低等级
12. 注册完成，用户可立即登录使用

### 5.2 商品发布流程
1. 平台管理员登录后台
2. 进入商品管理
3. 点击发布商品
4. 填写商品信息
5. 上传商品图片
6. 设置价格和库存
7. 设置商品分类和标签
8. 保存并上架商品
9. 商品展示在前端

### 5.3 下单流程
1. 采购者浏览商品
2. 选择商品加入购物车/立即购买
3. 进入购物车页面
4. 确认购物车商品信息
5. 点击"去结账"按钮
6. 进入结算页面（填写购物信息）
7. **填写收货人信息**
   - 选择已有收货地址或选择"其他收货地址"
   - 如选择新地址，填写：
     - 收货地区（省/市/区三级联动）
     - 街道地址
     - 邮编
     - 收货人姓名
     - 联系电话/联系手机
     - 选择是否保存地址
8. **选择配送日期和时间**
   - 选择送货日期
   - 选择时间段
   - 填写订单附言（可选）
9. **选择配送方式**
   - 查看配送方式
   - 如需修改，点击修改按钮
10. **选择支付方式**
    - 选择支付币别
    - 选择支付方式
    - 如需修改，点击修改按钮
11. **确认商品信息**
    - 查看购买的商品列表
    - 确认商品数量、价格
12. **确认订单金额明细**
    - 查看商品总价格
    - 查看配送费用
    - 查看税金
    - 填写发票抬头（可选）
    - 确认订单总金额
13. 点击"确认无误，下订单"按钮
14. 提交订单
15. 进行支付
16. 支付成功，订单生成
17. 平台收到订单通知

### 5.4 订单处理流程
1. 平台管理员收到订单通知
2. 查看订单详情
3. 确认订单
4. 准备商品
5. 填写物流信息并发货
6. 更新订单状态为"已发货"
7. 采购者收到发货通知
8. 采购者查询物流信息
9. 商品送达，采购者确认收货
10. 订单完成

### 5.5 支付结算流程
1. 采购者提交订单
2. 选择支付方式
3. 完成支付
4. 支付成功回调
5. 订单状态更新为"待发货"
6. 平台发货
7. 订单完成后，平台完成结算

### 5.6 用户登录流程
1. 用户访问登录页面
2. 查看页面提示："已注册用户, 请登录"
3. 输入用户名
4. 输入密码
5. 点击"立即登录"按钮
6. 系统验证用户名和密码
7. 验证成功，用户登录
8. 跳转到会员中心或首页
9. 验证失败，显示错误提示

### 5.7 密码找回流程
1. 用户在登录页面点击"忘记密码"链接
2. 跳转到忘记密码页面
3. 查看页面提示："如果忘记密码，请填写下面表单来重新获取密码"
4. 输入用户名
5. 点击提交按钮
6. 系统验证用户名是否存在
7. **如果用户不存在**：
   - 显示错误提示："该用户不存在！"
   - 显示自动跳转提示："10秒后系统会自动跳转，也可点击本处直接跳转"
   - 10秒后自动跳转或用户手动点击跳转
8. **如果用户存在**：
   - 系统发送密码重置信息到用户注册邮箱
   - 显示成功提示："密码重置信息已发送到您的邮箱，请查收"
   - 用户查收邮箱
   - 用户通过邮箱中的链接重置密码或使用新密码登录
   - 重置密码后，用户使用新密码登录
