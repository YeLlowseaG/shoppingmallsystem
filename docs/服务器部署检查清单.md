## 三、后端部署

### 3.1 打包后端项目（在本地执行）

```bash
cd backend
mvn clean package -DskipTests
```

打包后的jar文件位置：`backend/target/shopping-mall-system-1.0.0-SNAPSHOT.jar`

### 3.2 上传jar文件到服务器

```bash
# 上传到正式环境目录
scp backend/target/shopping-mall-system-1.0.0-SNAPSHOT.jar root@43.139.206.84:/www/wwwroot/shopping-mall-backend-prod/

# 上传到测试环境目录
scp backend/target/shopping-mall-system-1.0.0-SNAPSHOT.jar root@43.139.206.84:/www/wwwroot/shopping-mall-backend-test/
```

### 3.3 在宝塔面板配置Java项目

- [ ] 项目名称：`ShoppingMall-Backend-Prod`

## 四、前端部署

### 4.1 构建前端项目（在本地执行）

**方式一：使用构建脚本（推荐）**
```bash
# Windows
scripts\build-all.bat

# Linux/Mac
chmod +x scripts/build-all.sh
./scripts/build-all.sh
```

**方式二：手动构建**
```bash
# 正式环境用户端
cd frontend
npm install
npm run build -- --mode production
# 构建产物在 frontend/dist-prod/

# 正式环境管理后台
cd admin-frontend
npm install
npm run build -- --mode production
# 构建产物在 admin-frontend/dist-prod/

# 测试环境用户端
cd frontend
npm run build -- --mode test
# 构建产物在 frontend/dist-test/

# 测试环境管理后台
cd admin-frontend
npm run build -- --mode test
# 构建产物在 admin-frontend/dist-test/
```

### 4.2 上传前端构建产物

**注意**：正式环境和测试环境的构建产物分别在不同的目录（dist-prod 和 dist-test），互不干扰。

```bash
# 正式环境用户端
scp -r frontend/dist-prod/* root@43.139.206.84:/www/wwwroot/www.shop.quaichao.com/buyer/

# 正式环境管理后台
scp -r admin-frontend/dist-prod/* root@43.139.206.84:/www/wwwroot/www.shop.quaichao.com/admin/

# 测试环境用户端
scp -r frontend/dist-test/* root@43.139.206.84:/www/wwwroot/www.shop.quaichao.com/test-buyer/

# 测试环境管理后台
scp -r admin-frontend/dist-test/* root@43.139.206.84:/www/wwwroot/www.shop.quaichao.com/test-admin/
```

## 七、常见问题排查

### 7.1 前端路由404

**检查**：
- [ ] 确认Nginx配置中使用了`try_files`指令
- [ ] 确认前端构建时使用了正确的base路径
- [ ] 检查浏览器控制台是否有路径错误

### 7.2 API请求失败

**检查**：
- [ ] 确认后端服务已启动（检查端口8081和8082）
- [ ] 确认Nginx配置正确路由到对应端口
- [ ] 检查浏览器Network面板查看请求路径

### 7.3 静态资源404

**检查**：
- [ ] 确认前端构建时的base路径配置正确
- [ ] 确认Nginx的alias路径正确
- [ ] 检查文件权限

### 7.4 后端服务启动失败

**检查**：
- [ ] 检查端口是否被占用：`netstat -tlnp | grep 808`
- [ ] 检查日志文件：`/www/wwwroot/shopping-mall-backend-prod/logs/` 和 `/www/wwwroot/shopping-mall-backend-test/logs/`
- [ ] 检查数据库连接配置
