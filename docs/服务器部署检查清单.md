## 二、服务器目录准备

### 创建必要的目录结构

```bash
# 创建后端项目目录（正式环境）
mkdir -p /www/wwwroot/shopping-mall-backend-prod
mkdir -p /www/wwwroot/shopping-mall-backend-prod/uploads/images
mkdir -p /www/wwwroot/shopping-mall-backend-prod/uploads/documents

# 创建前端部署目录（子域名架构 - 正式环境）
# 正式环境用户端
mkdir -p /www/wwwroot/www.shop.quaichao.com/buyer
# 正式环境管理后台（独立子域名）
mkdir -p /www/wwwroot/admin.quaichao.com
# API服务目录（用于Nginx反向代理配置）
mkdir -p /www/wwwroot/api.quaichao.com

# 设置目录权限
chown -R www:www /www/wwwroot/shopping-mall-backend-prod
chown -R www:www /www/wwwroot/www.shop.quaichao.com
chown -R www:www /www/wwwroot/admin.quaichao.com
chown -R www:www /www/wwwroot/api.quaichao.com
```

## 三、后端部署

### 3.1 打包后端项目（在本地执行）

```bash
cd backend
mvn clean package -DskipTests
```

打包后的jar文件位置：`backend/target/shopping-mall-system-1.0.0-SNAPSHOT.jar`

### 3.2 上传jar文件到服务器

```bash
# 上传到正式环境目录
scp backend/target/shopping-mall-system-1.0.0-SNAPSHOT.jar root@43.139.206.84:/www/wwwroot/shopping-mall-backend-prod/

### 3.3 在宝塔面板配置Java项目

#### 正式环境项目配置
- [ ] 项目名称：`ShoppingMall-Backend-Prod`
- [ ] 项目路径：`/www/wwwroot/shopping-mall-backend-prod`
- [ ] 启动命令：`java -jar -Xms512m -Xmx1024m -Dspring.profiles.active=prod shopping-mall-system.jar`
- [ ] 端口：`8081`
- [ ] JDK版本：`17`
- [ ] 环境变量（可选）：
  ```
  DB_USERNAME=shopping_mall
  DB_PASSWORD=Abc@123456
  JWT_SECRET=your-production-secret-key-change-this
  FRONTEND_URL=https://www.shop.quaichao.com
  ```

### 3.4 启动后端服务

- [ ] 在宝塔面板Java项目管理中启动正式环境项目
- [ ] 检查日志确认服务启动成功
- [ ] 验证端口8081是否正常监听

## 四、前端部署

### 4.1 构建前端项目（在本地执行）

**方式一：使用构建脚本（推荐）**
```bash
# Windows
scripts\build-all.bat

# Linux/Mac
chmod +x scripts/build-all.sh
./scripts/build-all.sh
```

**方式二：手动构建**
```bash
# 正式环境用户端
cd frontend
npm install
npm run build -- --mode production
# 构建产物在 frontend/dist-prod/

# 正式环境管理后台
cd admin-frontend
npm install
npm run build -- --mode production
# 构建产物在 admin-frontend/dist-prod/
```

### 4.2 上传前端构建产物

```bash
# 正式环境用户端（www.shop.quaichao.com）
scp -r frontend/dist-prod/* root@43.139.206.84:/www/wwwroot/www.shop.quaichao.com/buyer/

# 正式环境管理后台（admin.quaichao.com - 独立子域名）
scp -r admin-frontend/dist-prod/* root@43.139.206.84:/www/wwwroot/admin.quaichao.com/
```

## 五、Nginx配置和SSL证书

### 5.1 创建三个独立站点

#### 5.1.1 创建用户端站点（www.shop.quaichao.com）
- [ ] 在宝塔面板中进入 `网站` → `添加站点`
- [ ] 域名：`www.shop.quaichao.com`
- [ ] 选择 `纯静态`
- [ ] 根目录：`/www/wwwroot/www.shop.quaichao.com/buyer`
- [ ] 点击 `提交`

#### 5.1.2 创建管理后台站点（admin.quaichao.com）
- [ ] 在宝塔面板中进入 `网站` → `添加站点`
- [ ] 域名：`admin.quaichao.com`
- [ ] 选择 `纯静态`
- [ ] 根目录：`/www/wwwroot/admin.quaichao.com`
- [ ] 点击 `提交`

#### 5.1.3 创建API服务站点（api.quaichao.com）
- [ ] 在宝塔面板中进入 `网站` → `添加站点`
- [ ] 域名：`api.quaichao.com`
- [ ] 选择 `纯静态`（后续会配置为反向代理）
- [ ] 根目录：`/www/wwwroot/api.quaichao.com`
- [ ] 点击 `提交`

### 5.2 配置SSL证书

为三个域名分别申请SSL证书：

#### 5.2.1 用户端SSL证书（www.shop.quaichao.com）
- [ ] 进入站点 `设置` → `SSL`
- [ ] 选择 `Let's Encrypt`，勾选 `www.shop.quaichao.com`
- [ ] 点击 `申请`，等待完成
- [ ] 开启 `强制HTTPS` 和 `HTTP/2`

#### 5.2.2 管理后台SSL证书（admin.quaichao.com）
- [ ] 进入站点 `设置` → `SSL`
- [ ] 选择 `Let's Encrypt`，勾选 `admin.quaichao.com`
- [ ] 点击 `申请`，等待完成
- [ ] 开启 `强制HTTPS` 和 `HTTP/2`

#### 5.2.3 API服务SSL证书（api.quaichao.com）
- [ ] 进入站点 `设置` → `SSL`
- [ ] 选择 `Let's Encrypt`，勾选 `api.quaichao.com`
- [ ] 点击 `申请`，等待完成
- [ ] 开启 `强制HTTPS` 和 `HTTP/2`

**重要**：API服务必须使用HTTPS，因为微信支付和支付宝支付回调要求HTTPS。

### 5.3 配置Nginx反向代理

#### 5.3.1 用户端站点配置（www.shop.quaichao.com）
- [ ] 进入站点 `设置` → `配置文件`
- [ ] 参考 `docs/完全隔离环境部署方案.md` 中用户端Nginx配置
- [ ] 点击 `保存`

#### 5.3.2 管理后台站点配置（admin.quaichao.com）
- [ ] 进入站点 `设置` → `配置文件`
- [ ] 参考 `docs/完全隔离环境部署方案.md` 中管理后台Nginx配置
- [ ] 点击 `保存`

#### 5.3.3 API服务站点配置（api.quaichao.com）
- [ ] 进入站点 `设置` → `配置文件`
- [ ] 参考 `docs/完全隔离环境部署方案.md` 中API服务Nginx配置
- [ ] 配置反向代理到 `http://127.0.0.1:8081`（正式环境）
- [ ] 点击 `保存`

### 5.4 测试并重载Nginx

```bash
# 测试配置
nginx -t

# 如果测试通过，重载配置
nginx -s reload
# 或在宝塔面板点击"重载配置"
```

## 七、常见问题排查

### 7.1 前端路由404

**检查**：
- [ ] 确认Nginx配置中使用了`try_files`指令
- [ ] 确认前端构建时使用了正确的base路径
- [ ] 检查浏览器控制台是否有路径错误

### 7.2 API请求失败

**检查**：
- [ ] 确认后端服务已启动（检查端口8081和8082）
- [ ] 确认api.quaichao.com的Nginx配置正确反向代理到8081端口
- [ ] 确认前端环境变量`VITE_API_BASE_URL`配置为`https://api.quaichao.com`
- [ ] 检查浏览器Network面板查看请求路径
- [ ] 检查SSL证书是否正常（API服务必须使用HTTPS）

### 7.3 静态资源404

**检查**：
- [ ] 确认前端构建时的base路径配置正确
- [ ] 确认Nginx的alias路径正确
- [ ] 检查文件权限

### 7.4 后端服务启动失败

**检查**：
- [ ] 检查端口是否被占用：`netstat -tlnp | grep 8081`
- [ ] 检查日志文件：`/www/wwwroot/shopping-mall-backend-prod/logs/shopping-mall.log`
- [ ] 检查数据库连接配置
- [ ] 检查Java版本是否正确（需要JDK 17+）
