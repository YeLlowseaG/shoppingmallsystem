# Test Documentation

This directory contains test documentation for various modules of the Shopping Mall System.

## Directory Structure

```
docs/test/
├── README.md                          # This file
├── logistics-management-test.md       # Logistics management module test guide
└── ...                                # Other test documents
```

## Test Documents

### Logistics Management Module
- **File**: `logistics-management-test.md`
- **Description**: Complete test guide for logistics management module including database initialization, API testing, frontend testing, and troubleshooting
- **Last Updated**: 2025-12-09

## Naming Convention

Test documents follow this naming convention:
- Format: `{module-name}-test.md`
- Use lowercase letters and hyphens
- Examples:
  - `logistics-management-test.md`
  - `order-management-test.md`
  - `user-management-test.md`

## Adding New Test Documents

When adding a new test document:

1. Create the file in `docs/test/` directory
2. Follow the naming convention: `{module-name}-test.md`
3. Include the following sections:
   - Database initialization (if applicable)
   - Backend API testing
   - Frontend testing
   - Troubleshooting
   - Test checklist
4. Update this README.md to include the new document
