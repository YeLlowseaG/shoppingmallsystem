## 1. 系统简介

趣爱巢商城管理后台是商城系统的管理平台，管理员可以通过后台管理系统进行商品管理、订单处理、用户管理、数据统计等操作。

### 1.1 主要功能模块

- **首页**：数据概览、统计图表
- **商品管理**：商品列表、商品发布、商品分类管理
- **订单管理**：订单列表、订单详情、订单发货
- **库存管理**：库存列表、库存调整、库存预警
- **采购者管理**：采购者列表、等级管理
- **营销管理**：促销活动、价格策略
- **数据统计**：销售统计、订单统计、商品统计、采购者统计
- **系统设置**：基础配置、支付配置、物流配置、通知设置
- **权限管理**：用户管理、角色管理、菜单管理

### 1.2 访问地址

- 管理后台访问地址：https://admin.quaichao.com

### 1.3 权限说明

系统支持多种角色，不同角色拥有不同的权限：

- **超级管理员**：拥有所有功能权限
- **运营人员**：拥有商品、订单、库存、采购者、营销、数据统计模块权限
- **客服人员**：拥有订单、采购者管理模块权限
- **财务人员**：拥有订单、数据统计模块权限

## 2. 登录系统

### 2.1 管理员登录

#### 2.1.1 登录步骤

1. 访问管理后台地址：https://admin.quaichao.com
2. 系统会自动跳转到登录页面
3. 在登录页面输入登录信息：
   - **用户名**：输入管理员用户名
   - **密码**：输入登录密码
   - **验证码**：输入图片验证码
4. 点击"登录"按钮

> **提示**：登录成功后，系统会自动跳转到首页（数据概览页面）。

#### 2.1.2 登录注意事项

- 用户名和密码区分大小写
- 验证码不区分大小写
- 如果连续多次登录失败，系统可能会暂时锁定账户
- 建议使用Chrome、Firefox等现代浏览器访问

### 2.2 退出登录

1. 点击页面右上角的用户名或头像
2. 在下拉菜单中选择"退出登录"
3. 确认退出后，系统会清除登录状态并跳转到登录页

> **提示**：退出登录后，需要重新登录才能访问管理后台。

## 3. 首页概览

### 3.1 首页功能

登录成功后，系统会跳转到首页（数据概览页面）。首页显示以下内容：

#### 3.1.1 数据统计卡片

首页顶部显示多个数据统计卡片，包括：

- **今日销售额**：显示今日的销售总金额
- **今日订单数**：显示今日的订单总数
- **待处理订单**：显示待发货的订单数量
- **库存预警**：显示库存不足的商品数量
- **采购者总数**：显示注册的采购者总数
- **商品总数**：显示上架的商品总数

> **提示**：点击统计卡片可以跳转到对应的详细页面。

#### 3.1.2 统计图表

首页中间显示多个统计图表：

- **销售趋势图**：显示最近一段时间的销售趋势（折线图）
- **订单趋势图**：显示最近一段时间的订单趋势（折线图）
- **订单状态分布**：显示不同状态订单的分布情况（饼图）

> **提示**：图表支持时间范围选择，可以查看不同时间段的数据。

#### 3.1.3 快捷操作

首页右侧或底部可能显示快捷操作入口：

- **待处理订单**：快速查看待处理的订单
- **库存预警**：快速查看库存不足的商品
- **最新订单**：显示最新的订单列表

### 3.2 刷新数据

1. 在首页顶部，点击"刷新数据"按钮
2. 系统会重新加载所有统计数据
3. 刷新完成后，所有图表和数据会更新为最新数据

> **提示**：刷新过程中按钮会显示加载状态，请勿重复点击。

## 4. 商品管理

### 4.1 商品列表

#### 4.1.1 进入商品列表

1. 在左侧菜单中，点击"商品管理" → "商品列表"
2. 系统会显示商品列表页面

#### 4.1.2 商品列表功能

商品列表页面包含以下功能：

- **状态标签页**：顶部显示4个状态标签页
  - **全部**：显示所有未删除的商品
  - **已上架**：只显示已上架的商品
  - **已下架**：只显示已下架的商品
  - **草稿**：只显示草稿状态的商品
- **搜索栏**：支持多条件搜索
  - **商品名称/编号**：输入商品名称或编号进行搜索
  - **商品分类**：选择商品分类进行筛选（支持多级分类）
  - **商品状态**：选择商品状态进行筛选
  - **品牌**：选择品牌进行筛选
- **商品列表**：显示商品信息
  - 商品图片
  - 商品名称和编号
  - 商品分类
  - 商品价格（基础价）
  - 库存数量
  - 商品状态
  - 操作按钮（编辑、删除等）

#### 4.1.3 商品操作

在商品列表中，您可以进行以下操作：

1. **查看商品详情**：点击商品名称或图片，查看商品详细信息
2. **编辑商品**：点击"编辑"按钮，修改商品信息
3. **删除商品**：点击"删除"按钮，删除商品（逻辑删除）
4. **上架/下架**：点击"上架"或"下架"按钮，修改商品状态

> **提示**：
> - 删除的商品不会在列表中显示（逻辑删除）
> - 下架的商品不会在前端显示，但管理员仍可查看
> - 草稿状态的商品不会在前端显示

### 4.2 商品发布

#### 4.2.1 进入商品发布页面

1. 在左侧菜单中，点击"商品管理" → "商品发布"
2. 系统会显示商品发布页面（新建商品表单）

#### 4.2.2 填写商品信息

商品发布表单包含以下必填和可选字段：

**基本信息**：
- **商品名称**：输入商品名称（必填）
- **商品编号**：输入商品编号，系统会自动生成（必填）
- **商品分类**：选择商品分类，支持多级分类（必填）
- **品牌**：选择商品品牌（可选）
- **商品状态**：选择商品状态（上架/下架/草稿）（必填）

**价格和库存**：
- **基础价格**：输入商品基础价格（必填）
- **库存数量**：输入商品库存数量（必填）
- **警戒库存**：输入库存预警阈值（可选）

**商品图片**：
- **主图**：上传商品主图（必填，建议尺寸：800x800px）
- **详情图**：上传商品详情图片（可选，可上传多张）

**商品描述**：
- **商品简介**：输入商品简短描述（可选）
- **商品详情**：输入商品详细描述，支持富文本编辑（可选）

**其他设置**：
- **运费模板**：选择运费模板（可选）
- **商品规格**：如果商品有规格（如颜色、尺寸），可以添加规格（可选）

#### 4.2.3 保存商品

填写完商品信息后：

1. **保存为草稿**：点击"保存草稿"按钮，商品会保存为草稿状态
2. **保存并上架**：点击"保存并上架"按钮，商品会保存并立即上架
3. **保存并下架**：点击"保存并下架"按钮，商品会保存但处于下架状态

> **提示**：
> - 草稿状态的商品不会在前端显示
> - 上架的商品会立即在前端显示
> - 下架的商品不会在前端显示，但可以重新上架

### 4.3 商品编辑

#### 4.3.1 编辑商品

1. 在商品列表中，找到要编辑的商品
2. 点击"编辑"按钮
3. 系统会跳转到商品编辑页面（与商品发布页面相同，但已填充商品信息）
4. 修改商品信息
5. 点击"保存"按钮保存修改

> **提示**：编辑商品时，商品编号不能修改。

### 4.4 商品分类管理

#### 4.4.1 进入分类管理

1. 在左侧菜单中，点击"商品管理" → "商品分类"
2. 系统会显示商品分类管理页面

#### 4.4.2 分类列表

分类管理页面以树形结构显示所有商品分类：

- **分类树**：左侧或顶部显示分类树，支持展开/折叠
- **分类信息**：显示分类名称、排序、状态等
- **操作按钮**：编辑、删除、添加子分类等

#### 4.4.3 添加分类

1. 点击"添加分类"按钮
2. 填写分类信息：
   - **分类名称**：输入分类名称（必填）
   - **父分类**：选择父分类，如果不选择则为一级分类（可选）
   - **排序**：输入排序值，数字越小越靠前（可选）
   - **状态**：选择启用/禁用（必填）
3. 点击"保存"按钮

#### 4.4.4 编辑分类

1. 在分类列表中，找到要编辑的分类
2. 点击"编辑"按钮
3. 修改分类信息
4. 点击"保存"按钮

> **提示**：修改父分类会影响分类的层级关系。

#### 4.4.5 删除分类

1. 在分类列表中，找到要删除的分类
2. 点击"删除"按钮
3. 系统会弹出确认对话框
4. 确认删除后，分类会被删除

> **警告**：删除分类前，请确保该分类下没有商品，否则可能影响商品显示。

### 4.5 批量导入商品

#### 4.5.1 进入批量导入

1. 在商品列表页面，点击"批量导入"按钮
2. 系统会弹出批量导入对话框

#### 4.5.2 导入步骤

1. **下载模板**：点击"下载导入模板"按钮，下载CSV或Excel模板文件
2. **填写数据**：按照模板格式填写商品数据
   - 必填字段：商品名称、商品编号、商品分类、基础价格、库存数量
   - 可选字段：品牌、商品状态、警戒库存、商品简介等
3. **上传文件**：点击"选择文件"按钮，选择填写好的CSV或Excel文件
4. **开始导入**：点击"开始导入"按钮

> **提示**：
> - 单次最多导入200条商品数据
> - 如果数据超过200条，请分批导入
> - 支持CSV和Excel（.xlsx/.xls）格式

#### 4.5.3 导入结果

导入完成后，系统会显示导入结果：

- **成功数量**：显示成功导入的商品数量
- **失败数量**：显示导入失败的商品数量
- **失败详情**：显示失败的原因和行号

> **提示**：如果导入失败，请根据错误提示修改数据后重新导入。
