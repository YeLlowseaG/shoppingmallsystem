## 一、环境准备

### 1.1 服务器要求

- **操作系统**: Linux (CentOS 7+/Ubuntu 18+)
- **Java版本**: JDK 17 或更高版本
- **内存**: 最低 2GB，推荐 4GB+
- **磁盘空间**: 最低 10GB
- **数据库**: MySQL 8.0+

### 1.2 宝塔面板环境准备

#### 1.2.1 安装必要软件

1. **安装Java 17**
   - 登录宝塔面板
   - 进入 `软件商店` → `运行环境`
   - 搜索并安装 `Java` (选择JDK 17版本)
   - 或使用命令行安装：
     ```bash
     # CentOS
     yum install java-17-openjdk java-17-openjdk-devel -y
     
     # Ubuntu
     apt-get install openjdk-17-jdk -y
     ```

2. **安装MySQL 8.0**
   - 进入 `软件商店` → `数据库`
   - 安装 `MySQL 8.0`
   - 记录数据库root密码

3. **安装Maven（可选，用于在服务器上编译）**
   ```bash
   # CentOS
   yum install maven -y
   
   # Ubuntu
   apt-get install maven -y
   ```

#### 1.2.2 创建项目目录

在服务器上创建项目部署目录：

```bash
mkdir -p /www/wwwroot/shopping-mall-backend
mkdir -p /www/wwwroot/shopping-mall-backend/uploads/images
mkdir -p /www/wwwroot/shopping-mall-backend/uploads/documents
mkdir -p /www/wwwroot/shopping-mall-backend/logs

# 设置目录权限
chmod -R 755 /www/wwwroot/shopping-mall-backend/uploads
chmod -R 755 /www/wwwroot/shopping-mall-backend/logs
```

## 二、配置文件修改

### 2.1 修改主配置文件 `application.yml`

需要修改 `backend/src/main/resources/application.yml`：

**关键修改点：**
```yaml
spring:
  profiles:
    active: prod  # 从 local 改为 prod，激活生产环境配置
```

### 2.2 完善生产环境配置 `application-prod.yml`

生产环境配置文件位于：`backend/src/main/resources/application-prod.yml`

**必须修改的配置项：**

1. **数据库配置**
   ```yaml
   spring:
     datasource:
       url: jdbc:mysql://localhost:3306/chengren_shopping_mall?useUnicode=true&characterEncoding=utf8&useSSL=false&serverTimezone=Asia/Shanghai&allowPublicKeyRetrieval=true
       username: ${DB_USERNAME:root}  # 修改为实际数据库用户名
       password: ${DB_PASSWORD:your_password}  # 修改为实际数据库密码
   ```

2. **文件上传路径**
   ```yaml
   file:
     upload:
       path: /www/wwwroot/shopping-mall-backend/uploads
       image-path: /www/wwwroot/shopping-mall-backend/uploads/images
       document-path: /www/wwwroot/shopping-mall-backend/uploads/documents
   ```

3. **前端地址**
   ```yaml
   app:
     frontend:
       url: http://your-test-domain.com  # 修改为测试环境前端地址
   ```

4. **JWT密钥（生产环境必须修改）**
   ```yaml
   jwt:
     secret: shopping-mall-secret-key-production-2025-12-21-change-this
   ```

5. **Swagger配置（生产环境建议关闭）**
   ```yaml
   springdoc:
     swagger-ui:
       enabled: false  # 测试环境可以开启，生产环境建议关闭
   ```

### 2.3 使用环境变量（推荐）

为了安全，建议使用环境变量配置敏感信息。在服务器上创建环境变量文件：

```bash
# 创建环境变量文件
vim /www/wwwroot/shopping-mall-backend/.env

# 内容示例：
export DB_USERNAME=root
export DB_PASSWORD=your_secure_password
export JWT_SECRET=your_complex_jwt_secret_key
export FRONTEND_URL=http://your-test-domain.com
export SWAGGER_ENABLED=true
```

### 4.3 创建启动脚本

#### 4.3.1 创建启动脚本 `start.sh`

在 `/www/wwwroot/shopping-mall-backend/` 目录创建 `start.sh`：

```bash
#!/bin/bash

# 项目目录
APP_DIR="/www/wwwroot/shopping-mall-backend"
APP_NAME="shopping-mall-system-1.0.0-SNAPSHOT.jar"
PID_FILE="$APP_DIR/app.pid"
LOG_FILE="$APP_DIR/logs/startup.log"

# 进入项目目录
cd $APP_DIR

# 检查是否已经运行
if [ -f "$PID_FILE" ]; then
    PID=$(cat $PID_FILE)
    if ps -p $PID > /dev/null 2>&1; then
        echo "应用已在运行中，PID: $PID"
        exit 1
    else
        rm -f $PID_FILE
    fi
fi

# 加载环境变量（如果存在）
if [ -f "$APP_DIR/.env" ]; then
    source $APP_DIR/.env
fi

# 启动应用
echo "正在启动应用..."
nohup java -jar \
    -Xms512m \
    -Xmx1024m \
    -XX:MetaspaceSize=256m \
    -XX:MaxMetaspaceSize=512m \
    -Dspring.profiles.active=prod \
    -Dfile.encoding=UTF-8 \
    $APP_NAME \
    > $LOG_FILE 2>&1 &

# 保存PID
echo $! > $PID_FILE

# 等待启动
sleep 3

# 检查是否启动成功
if ps -p $(cat $PID_FILE) > /dev/null 2>&1; then
    echo "应用启动成功，PID: $(cat $PID_FILE)"
    echo "日志文件: $LOG_FILE"
else
    echo "应用启动失败，请查看日志: $LOG_FILE"
    rm -f $PID_FILE
    exit 1
fi
```

#### 4.3.2 创建停止脚本 `stop.sh`

```bash
#!/bin/bash

APP_DIR="/www/wwwroot/shopping-mall-backend"
PID_FILE="$APP_DIR/app.pid"

if [ ! -f "$PID_FILE" ]; then
    echo "应用未运行"
    exit 1
fi

PID=$(cat $PID_FILE)

if ! ps -p $PID > /dev/null 2>&1; then
    echo "应用未运行"
    rm -f $PID_FILE
    exit 1
fi

echo "正在停止应用，PID: $PID"
kill $PID

# 等待进程结束
for i in {1..30}; do
    if ! ps -p $PID > /dev/null 2>&1; then
        echo "应用已停止"
        rm -f $PID_FILE
        exit 0
    fi
    sleep 1
done

# 如果30秒后仍未停止，强制杀死
echo "应用未正常停止，强制终止..."
kill -9 $PID
rm -f $PID_FILE
echo "应用已强制停止"
```

#### 4.3.3 创建重启脚本 `restart.sh`

```bash
#!/bin/bash

APP_DIR="/www/wwwroot/shopping-mall-backend"

cd $APP_DIR
./stop.sh
sleep 2
./start.sh
```

#### 4.3.4 设置脚本权限

## 六、Nginx反向代理配置

如果需要通过域名访问API，需要配置Nginx反向代理。

### 6.1 在宝塔面板创建站点

1. 进入 `网站` → `添加站点`
2. 填写域名：`api.your-domain.com`
3. 选择 `纯静态` 或 `PHP项目`（不影响，后续会修改配置）

### 6.2 配置Nginx反向代理

1. 进入 `网站` → 选择创建的站点 → `设置` → `配置文件`
2. 修改配置如下：

```nginx
server {
    listen 80;
    server_name api.your-domain.com;  # 修改为你的域名
    
    # 日志配置
    access_log /www/wwwlogs/api.your-domain.com.log;
    error_log /www/wwwlogs/api.your-domain.com.error.log;

    # 客户端最大上传文件大小
    client_max_body_size 50M;

    location / {
        proxy_pass http://127.0.0.1:8081;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        
        # WebSocket支持（如果需要）
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        
        # 超时设置
        proxy_connect_timeout 60s;
        proxy_send_timeout 60s;
        proxy_read_timeout 60s;
        
        # 缓冲设置
        proxy_buffering off;
        proxy_request_buffering off;
    }

    # 静态资源缓存（可选）
    location ~* \.(jpg|jpeg|png|gif|ico|css|js)$ {
        proxy_pass http://127.0.0.1:8081;
        expires 30d;
        add_header Cache-Control "public, immutable";
    }
}
```

3. 保存配置并重载Nginx：
   ```bash
   nginx -t  # 测试配置
   nginx -s reload  # 重载配置
   ```

### 6.3 配置SSL证书（HTTPS）

1. 在宝塔面板 `网站` → 选择站点 → `设置` → `SSL`
2. 选择 `Let's Encrypt` 免费证书
3. 点击 `申请` 并等待证书申请完成
4. 开启 `强制HTTPS`

### 6.4 修改后端配置支持HTTPS

如果使用HTTPS，需要修改 `application-prod.yml`：

```yaml
server:
  port: 8081
  servlet:
    context-path: /
  # 如果使用Nginx反向代理，可以添加以下配置
  forward-headers-strategy: framework
```

## 七、常见问题排查

### 7.1 应用无法启动

**检查清单：**
- [ ] Java版本是否正确（需要JDK 17+）
- [ ] jar文件是否存在且完整
- [ ] 配置文件是否正确
- [ ] 端口是否被占用
- [ ] 日志文件是否有错误信息

**查看日志：**
```bash
tail -100 /www/wwwroot/shopping-mall-backend/logs/shopping-mall.log
tail -100 /www/wwwroot/shopping-mall-backend/logs/startup.log
```

### 7.2 数据库连接问题

**错误信息示例：**
```
Communications link failure
Access denied for user
```

**解决方案：**
1. 检查数据库服务状态
2. 验证用户名密码
3. 检查数据库是否已创建
4. 检查MySQL用户权限
5. 检查防火墙设置

### 7.3 文件上传失败

**检查项：**
- 上传目录是否存在
- 目录权限是否正确（755）
- 文件大小是否超过限制
- 磁盘空间是否充足

**解决方案：**
```bash
# 检查目录权限
ls -la /www/wwwroot/shopping-mall-backend/uploads

# 设置权限
chmod -R 755 /www/wwwroot/shopping-mall-backend/uploads
chown -R www:www /www/wwwroot/shopping-mall-backend/uploads
```

### 7.4 内存溢出

**错误信息：**
```
OutOfMemoryError: Java heap space
```

**解决方案：**
1. 增加JVM内存参数：
   ```bash
   -Xms1024m -Xmx2048m
   ```
2. 检查服务器内存使用情况
3. 优化应用代码

### 7.5 性能问题

**优化建议：**
1. 调整数据库连接池大小
2. 启用缓存机制
3. 优化SQL查询
4. 使用CDN加速静态资源
5. 启用Gzip压缩
