# 完全隔离环境部署方案

## 一、方案概述

本方案实现在同一个域名下部署完全隔离的正式环境和测试环境，通过路径区分：
- **正式环境**：`www.shop.quaichao.com/` 和 `www.shop.quaichao.com/admin`
- **测试环境**：`www.shop.quaichao.com/test` 和 `www.shop.quaichao.com/test/admin`

### 架构说明

- **后端**：两个独立的Java项目，使用不同端口和数据库
  - 正式环境：端口 8081，数据库 `shopping_mall_prod`
  - 测试环境：端口 8082，数据库 `shopping_mall_test`
- **前端**：两套独立的构建产物
  - 正式环境：`/buyer` 和 `/admin`
  - 测试环境：`/test-buyer` 和 `/test-admin`
- **Nginx**：通过路径路由到不同的后端服务

### 2.3 在宝塔面板部署两个Java项目

#### 正式环境项目配置

1. **项目名称**：`ShoppingMall-Backend-Prod`
2. **项目路径**：`/www/wwwroot/shopping-mall-backend-prod`
3. **启动命令**：
   ```bash
   java -jar shopping-mall-system.jar --spring.profiles.active=prod
   ```
4. **端口**：`8081`
5. **环境变量**（可选，在宝塔面板Java项目管理中配置）：
   ```bash
   DB_USERNAME=shopping_mall
   DB_PASSWORD=Abc@123456
   JWT_SECRET=your-production-secret-key
   FRONTEND_URL=http://www.shop.quaichao.com
   ```

#### 测试环境项目配置

1. **项目名称**：`ShoppingMall-Backend-Test`
2. **项目路径**：`/www/wwwroot/shopping-mall-backend-test`
3. **启动命令**：
   ```bash
   java -jar shopping-mall-system.jar --spring.profiles.active=test
   ```
4. **端口**：`8082`
5. **环境变量**（可选，在宝塔面板Java项目管理中配置）：
   ```bash
   DB_USERNAME=shopping_mall
   DB_PASSWORD=Abc@123456
   JWT_SECRET=your-test-secret-key
   FRONTEND_URL=http://www.shop.quaichao.com/test
   ```

### 2.4 项目打包

两个环境使用同一个jar包，通过不同的profile启动：

```bash
# 在项目根目录执行
cd backend
mvn clean package -DskipTests

# 打包后的jar文件位置
# backend/target/shopping-mall-system.jar
```

将打包好的jar文件分别复制到两个项目目录：
```bash
# 正式环境
cp backend/target/shopping-mall-system.jar /www/wwwroot/shopping-mall-backend-prod/

# 测试环境
cp backend/target/shopping-mall-system.jar /www/wwwroot/shopping-mall-backend-test/
```

### 3.2 修改前端构建配置

#### 用户端配置（frontend/vite.config.ts）

```typescript
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import { resolve } from 'path'

export default defineConfig({
  plugins: [vue()],
  resolve: {
    alias: {
      '@': resolve(__dirname, 'src')
    }
  },
  // 根据环境变量设置base路径
  base: process.env.VITE_BUILD_ENV === 'test' ? '/test/' : '/',
  server: {
    port: 3002,
    proxy: {
      '/api': {
        target: 'http://localhost:8081',
        changeOrigin: true
      },
      '/test/api': {
        target: 'http://localhost:8082',
        changeOrigin: true,
        rewrite: (path) => path.replace(/^\/test/, '')
      },
      '/uploads': {
        target: 'http://localhost:8081',
        changeOrigin: true
      }
    }
  },
  build: {
    outDir: 'dist',
    assetsDir: 'assets',
    sourcemap: false,
    minify: 'esbuild'
  }
})
```

## 四、Nginx配置

### 4.1 完整Nginx配置

在宝塔面板中，找到 `www.shop.quaichao.com` 站点的配置文件，替换为以下配置：

```nginx
server {
    listen 80;
    listen 443 ssl http2;
    server_name www.shop.quaichao.com;
    
    # SSL证书配置（如果使用HTTPS）
    # ssl_certificate /www/server/panel/vhost/cert/www.shop.quaichao.com/fullchain.pem;
    # ssl_certificate_key /www/server/panel/vhost/cert/www.shop.quaichao.com/privkey.pem;
    
    # 日志配置
    access_log /www/wwwlogs/www.shop.quaichao.com.log;
    error_log /www/wwwlogs/www.shop.quaichao.com.error.log;
    
    # 文件上传大小限制
    client_max_body_size 50M;
    
    # ============================================
    # 测试环境 - 管理后台前端（静态文件）
    # ============================================
    location ~ ^/test/admin(/.*)?$ {
        alias /www/wwwroot/www.shop.quaichao.com/test-admin;
        index index.html;
        try_files $uri $uri/ /test/admin/index.html;
        
        # 静态资源缓存
        location ~* \.(jpg|jpeg|png|gif|ico|css|js|svg|woff|woff2|ttf|eot)$ {
            expires 30d;
            add_header Cache-Control "public, immutable";
            access_log off;
        }
    }
    
    # ============================================
    # 测试环境 - 用户端前端（静态文件）
    # ============================================
    location ~ ^/test(/.*)?$ {
        # 排除 /test/admin 和 /test/api
        if ($uri ~ ^/test/admin) {
            break;
        }
        if ($uri ~ ^/test/api) {
            break;
        }
        
        alias /www/wwwroot/www.shop.quaichao.com/test-buyer;
        index index.html;
        try_files $uri $uri/ /test/index.html;
        
        # 静态资源缓存
        location ~* \.(jpg|jpeg|png|gif|ico|css|js|svg|woff|woff2|ttf|eot)$ {
            expires 30d;
            add_header Cache-Control "public, immutable";
            access_log off;
        }
    }
    
    # ============================================
    # 测试环境 - API后端（端口8082）
    # ============================================
    location /test/api/ {
        # 去掉/test前缀，转发到测试环境后端
        rewrite ^/test/api/(.*)$ /api/$1 break;
        
        # 代理到测试环境后端（端口8082）
        proxy_pass http://127.0.0.1:8082/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        
        # WebSocket支持
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        
        # 超时设置
        proxy_connect_timeout 60s;
        proxy_send_timeout 60s;
        proxy_read_timeout 60s;
        
        # 缓冲设置
        proxy_buffering off;
        proxy_request_buffering off;
    }
    
    # ============================================
    # 正式环境 - 管理后台前端（静态文件）
    # ============================================
    location /admin {
        alias /www/wwwroot/www.shop.quaichao.com/admin;
        index index.html;
        try_files $uri $uri/ /admin/index.html;
        
        # 静态资源缓存
        location ~* \.(jpg|jpeg|png|gif|ico|css|js|svg|woff|woff2|ttf|eot)$ {
            expires 30d;
            add_header Cache-Control "public, immutable";
            access_log off;
        }
    }
    
    # ============================================
    # 正式环境 - 用户端前端（静态文件）
    # ============================================
    location / {
        # 排除 /admin 和 /api 和 /test
        if ($uri ~ ^/admin) {
            break;
        }
        if ($uri ~ ^/api) {
            break;
        }
        if ($uri ~ ^/test) {
            break;
        }
        
        root /www/wwwroot/www.shop.quaichao.com/buyer;
        index index.html;
        try_files $uri $uri/ /index.html;
        
        # 静态资源缓存
        location ~* \.(jpg|jpeg|png|gif|ico|css|js|svg|woff|woff2|ttf|eot)$ {
            expires 30d;
            add_header Cache-Control "public, immutable";
            access_log off;
        }
    }
    
    # ============================================
    # 正式环境 - API后端（端口8081）
    # ============================================
    location /api/ {
        # 代理到正式环境后端（端口8081）
        proxy_pass http://127.0.0.1:8081/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        
        # WebSocket支持
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        
        # 超时设置
        proxy_connect_timeout 60s;
        proxy_send_timeout 60s;
        proxy_read_timeout 60s;
        
        # 缓冲设置
        proxy_buffering off;
        proxy_request_buffering off;
    }
    
    # ============================================
    # 文件上传目录（根据环境区分）
    # ============================================
    # 正式环境上传目录
    location /uploads/ {
        alias /www/wwwroot/shopping-mall-backend-prod/uploads/;
        expires 30d;
        add_header Cache-Control "public, immutable";
        
        # 只允许访问图片和文档文件
        location ~* \.(jpg|jpeg|png|gif|pdf|doc|docx|xls|xlsx)$ {
            access_log off;
        }
        
        # 禁止访问其他文件类型
        location ~* \.(php|jsp|asp|aspx|sh|bat|exe)$ {

        }
    }
    
    # 测试环境上传目录
    location /test/uploads/ {
        alias /www/wwwroot/shopping-mall-backend-test/uploads/;
        expires 30d;
        add_header Cache-Control "public, immutable";
        
        # 只允许访问图片和文档文件
        location ~* \.(jpg|jpeg|png|gif|pdf|doc|docx|xls|xlsx)$ {
            access_log off;
        }
        
        # 禁止访问其他文件类型

        }
    }
```

## 九、常见问题

### 9.1 前端路由问题

**问题**：测试环境前端路由404

**解决方案**：
- 确保vite.config.ts中设置了正确的base路径
- 确保Nginx配置中使用了`try_files`指令

### 9.2 API请求路径问题

**问题**：测试环境API请求失败

**解决方案**：
- 检查环境变量文件中的`VITE_API_BASE_URL`配置
- 确保Nginx配置正确路由到8082端口

### 9.3 静态资源404

**问题**：测试环境静态资源加载失败

**解决方案**：
- 检查前端构建时的base路径配置
- 确保Nginx的alias路径正确

### 9.4 后端服务启动失败

**问题**：端口被占用

**解决方案**：
- 检查8081和8082端口是否被占用：`netstat -tlnp | grep 808`
- 确保两个Java项目使用不同的端口
