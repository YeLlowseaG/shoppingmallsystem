# 完全隔离环境部署方案

## 一、方案概述

本方案采用子域名架构部署，所有环境均使用独立子域名，不使用路径方式。

### 正式环境架构
- **用户端**：`https://www.shop.quaichao.com/`（独立站点）
- **管理后台**：`https://admin.quaichao.com`（独立子域名）
- **API服务**：`https://api.quaichao.com`（独立子域名，反向代理到后端服务）

### 测试环境架构（如需测试环境，使用test前缀子域名）
- **用户端**：`https://test-www.shop.quaichao.com`（独立子域名）
- **管理后台**：`https://test-admin.quaichao.com`（独立子域名）
- **API服务**：`https://test-api.quaichao.com`（独立子域名）

### 架构说明

- **后端**：独立的Java项目，使用不同端口和数据库
  - 正式环境：端口 8081，数据库 `shopping_mall_prod`
  - 测试环境（如需）：端口 8082，数据库 `shopping_mall_test`，使用test前缀子域名
- **前端**：独立的构建产物
  - 正式环境用户端：部署在 `www.shop.quaichao.com`
  - 正式环境管理后台：部署在 `admin.quaichao.com`（独立子域名）
- **Nginx**：三个独立站点（正式环境）
  - `www.shop.quaichao.com`：用户端静态文件
  - `admin.quaichao.com`：管理后台静态文件
  - `api.quaichao.com`：反向代理到后端服务（端口8081）

### 为什么使用API子域名？

1. **支付回调要求**：微信支付和支付宝支付回调必须使用HTTPS，且需要完整的URL
2. **架构清晰**：API服务独立域名，便于管理和扩展
3. **安全隔离**：API服务可以独立配置安全策略
4. **符合规范**：符合RESTful API设计最佳实践

- 正式环境使用完整的HTTPS URL：`https://api.quaichao.com`
- 这样可以实现跨域访问，且符合支付回调的HTTPS要求
- 如需测试环境，使用test前缀子域名（如 `https://test-api.quaichao.com`），不使用路径方式

### 3.2 修改前端构建配置

#### 用户端配置（frontend/vite.config.ts）

```typescript
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import { resolve } from 'path'

export default defineConfig({
  plugins: [vue()],
  resolve: {
    alias: {
      '@': resolve(__dirname, 'src')
    }
  },
  // 用户端部署在根路径（独立域名）
  base: '/',
  server: {
    port: 3002,
    proxy: {
      // 开发环境代理到本地后端
      '/api': {
        target: 'http://localhost:8081',
        changeOrigin: true
      },
      '/test/api': {
        target: 'http://localhost:8082',
        changeOrigin: true,
        rewrite: (path) => path.replace(/^\/test/, '')
      }
    }
  },
  build: {
    outDir: process.env.VITE_BUILD_ENV === 'test' ? 'dist-test' : 'dist-prod',
    assetsDir: 'assets',
    sourcemap: false,
    minify: 'esbuild'
  }
})
```

#### 管理后台配置（admin-frontend/vite.config.ts）

```typescript
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import { resolve } from 'path'

export default defineConfig(({ command }) => {
  const isBuild = command === 'build'
  
  // 管理后台部署在独立域名，base路径为根路径
  const base = '/'

  return {
    plugins: [vue()],
    resolve: {
      alias: {
        '@': resolve(__dirname, 'src')
      }
    },
    base,
    server: {
      port: 3003,
      proxy: {
        // 开发环境代理到本地后端
        '/api': {
          target: 'http://localhost:8081',
          changeOrigin: true
        },
        '/test/api': {
          target: 'http://localhost:8082',
          changeOrigin: true,
          rewrite: (path) => path.replace(/^\/test/, '')
        }
      }
    },
    build: {
      outDir: process.env.VITE_BUILD_ENV === 'test' ? 'dist-test' : 'dist-prod',
      assetsDir: 'assets',
      sourcemap: false,
      minify: 'esbuild'
    }
  }
})
```

**配置说明**：
- 正式环境和测试环境：`base: '/'`，因为都部署在独立域名下
- 生产环境API地址通过环境变量`VITE_API_BASE_URL`配置为`https://api.quaichao.com`
- 测试环境API地址（如需）配置为`https://test-api.quaichao.com`
- 开发环境仍使用proxy代理到本地后端（`/test/api`代理仅用于本地开发测试）

## 四、Nginx配置和SSL证书

### 4.1 创建三个独立站点

#### 4.1.1 创建用户端站点（www.shop.quaichao.com）

在宝塔面板中：
1. 进入 `网站` → `添加站点`
2. 域名：`www.shop.quaichao.com`
3. 选择 `纯静态`
4. 根目录：`/www/wwwroot/www.shop.quaichao.com/buyer`
5. 点击 `提交`

#### 4.1.2 创建管理后台站点（admin.quaichao.com）

在宝塔面板中：
1. 进入 `网站` → `添加站点`
2. 域名：`admin.quaichao.com`
3. 选择 `纯静态`
4. 根目录：`/www/wwwroot/admin.quaichao.com`
5. 点击 `提交`

#### 4.1.3 创建API服务站点（api.quaichao.com）

在宝塔面板中：
1. 进入 `网站` → `添加站点`
2. 域名：`api.quaichao.com`
3. 选择 `纯静态`（后续会配置为反向代理）
4. 根目录：`/www/wwwroot/api.quaichao.com`
5. 点击 `提交`

### 4.2 配置SSL证书

为三个域名分别申请SSL证书（Let's Encrypt免费证书）：

#### 4.2.1 用户端SSL证书（www.shop.quaichao.com）
1. 进入站点 `设置` → `SSL`
2. 选择 `Let's Encrypt`，勾选 `www.shop.quaichao.com`
3. 点击 `申请`，等待完成
4. 开启 `强制HTTPS` 和 `HTTP/2`

#### 4.2.2 管理后台SSL证书（admin.quaichao.com）
1. 进入站点 `设置` → `SSL`
2. 选择 `Let's Encrypt`，勾选 `admin.quaichao.com`
3. 点击 `申请`，等待完成
4. 开启 `强制HTTPS` 和 `HTTP/2`

#### 4.2.3 API服务SSL证书（api.quaichao.com）
1. 进入站点 `设置` → `SSL`
2. 选择 `Let's Encrypt`，勾选 `api.quaichao.com`
3. 点击 `申请`，等待完成
4. 开启 `强制HTTPS` 和 `HTTP/2`

**重要**：API服务必须使用HTTPS，因为微信支付和支付宝支付回调要求HTTPS。

### 4.3 Nginx配置文件

#### 4.3.1 用户端站点配置（www.shop.quaichao.com）

在宝塔面板中，进入 `www.shop.quaichao.com` 站点 → `设置` → `配置文件`，替换为以下配置：

```nginx
server
{
    listen 80;
    listen 443 ssl http2;
    server_name www.shop.quaichao.com;
    index index.php index.html index.htm default.php default.htm default.html;
    root /www/wwwroot/www.shop.quaichao.com/buyer;
    
    #CERT-APPLY-CHECK--START
    include /www/server/panel/vhost/nginx/well-known/www.shop.quaichao.com.conf;
    #CERT-APPLY-CHECK--END
    include /www/server/panel/vhost/nginx/extension/www.shop.quaichao.com/*.conf;
    
    #SSL-START
    #error_page 404/404.html;
    #HTTP_TO_HTTPS_START
    set $isRedcert 1;
    if ($server_port != 443) {
        set $isRedcert 2;
    }
    if ( $uri ~ /\.well-known/ ) {
        set $isRedcert 1;
```

## 九、常见问题

### 9.1 前端路由问题

**问题**：测试环境前端路由404

**解决方案**：
- 确保vite.config.ts中设置了正确的base路径
- 确保Nginx配置中使用了`try_files`指令

### 9.2 API请求路径问题

**问题**：测试环境API请求失败

**解决方案**：
- 检查环境变量文件中的`VITE_API_BASE_URL`配置
- 确保Nginx配置正确路由到8082端口

### 9.3 静态资源404

**问题**：测试环境静态资源加载失败

**解决方案**：
- 检查前端构建时的base路径配置
- 确保Nginx的alias路径正确

### 9.4 后端服务启动失败

**问题**：端口被占用

**解决方案**：
- 检查8081和8082端口是否被占用：`netstat -tlnp | grep 808`
- 确保两个Java项目使用不同的端口
