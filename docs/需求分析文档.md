# 购物商城系统需求分析文档

## 一、项目概述

参考网站：http://shop.jingvo.com/

基于Spring Boot + Vue3 + MySQL技术栈，构建一个功能完善的电商购物商城系统。

## 三、第三方对接设计

### 3.1 支付接口对接

#### 3.1.1 支付宝支付
- **对接方式**：支付宝开放平台API
- **主要功能**：
  - 统一下单接口
  - 支付结果查询
  - 支付结果异步通知（回调）
  - 退款接口
- **配置项**：AppID、应用私钥、支付宝公钥、回调地址

#### 3.1.2 微信支付
- **对接方式**：微信支付商户平台API
- **主要功能**：
  - 统一下单接口（JSAPI/APP/H5）
  - 支付结果查询
  - 支付结果异步通知（回调）
  - 退款接口
- **配置项**：商户号、AppID、API密钥、证书文件、回调地址

### 3.2 物流接口对接

#### 3.2.1 快递100 API
- **对接方式**：快递100开放平台
- **主要功能**：
  - 物流单号查询
  - 物流轨迹实时跟踪
  - 物流状态推送
- **配置项**：API Key、回调地址

#### 3.2.2 菜鸟物流API（可选）
- **对接方式**：菜鸟网络开放平台
- **主要功能**：物流信息查询、电子面单打印

### 3.3 短信服务对接

#### 3.3.1 阿里云短信服务
- **对接方式**：阿里云短信服务API
- **主要功能**：
  - 发送验证码短信
  - 发送订单通知短信
  - 发送营销短信
- **配置项**：AccessKey、SecretKey、短信签名、模板ID

#### 3.3.2 腾讯云短信服务（备选）
- 功能类似，作为备选方案

### 3.4 邮件服务对接

#### 3.4.1 阿里云邮件推送
- **对接方式**：阿里云邮件推送API
- **主要功能**：
  - 发送订单确认邮件
  - 发送发货通知邮件
  - 发送营销邮件
- **配置项**：AccessKey、SecretKey、发信地址

### 3.5 第三方登录对接

#### 3.5.1 微信登录
- **对接方式**：微信开放平台OAuth2.0
- **主要功能**：微信扫码登录、获取用户信息
- **配置项**：AppID、AppSecret、回调地址

#### 3.5.2 QQ登录（可选）
- **对接方式**：QQ互联平台
- **主要功能**：QQ账号登录

### 3.6 文件存储对接

#### 3.6.1 阿里云OSS
- **对接方式**：阿里云对象存储服务
- **主要功能**：
  - 商品图片上传
  - 用户头像上传
  - 文件访问CDN加速
- **配置项**：AccessKey、SecretKey、Bucket名称、Endpoint

#### 3.6.2 腾讯云COS（备选）
- 功能类似，作为备选方案

### 3.7 地图服务对接（可选）

#### 3.7.1 高德地图API
- **对接方式**：高德开放平台
- **主要功能**：
  - 地址解析（地址转坐标）
  - 距离计算
  - 地图展示
- **配置项**：API Key

## 四、技术架构设计

### 4.1 后端架构（Spring Boot）

#### 4.1.1 技术栈
- **框架**：Spring Boot 2.7+
- **数据库**：MySQL 8.0+
- **ORM**：MyBatis-Plus
- **缓存**：Redis
- **消息队列**：RabbitMQ（可选，用于异步处理）
- **安全框架**：Spring Security + JWT
- **API文档**：Swagger/Knife4j
- **工具类**：Hutool、Lombok

#### 4.1.2 项目结构
```
backend/
├── src/main/java/com/shoppingmall/
│   ├── controller/        # 控制器层
│   ├── service/          # 业务逻辑层
│   ├── mapper/           # 数据访问层
│   ├── entity/           # 实体类
│   ├── dto/              # 数据传输对象
│   ├── vo/               # 视图对象
│   ├── config/           # 配置类
│   ├── utils/            # 工具类
│   ├── common/           # 通用类（常量、异常、响应等）
│   └── interceptor/      # 拦截器
├── src/main/resources/
│   ├── mapper/           # MyBatis XML映射文件
│   ├── application.yml   # 配置文件
│   └── application-dev.yml
└── pom.xml
```

#### 4.1.3 核心模块
- **用户模块**：注册、登录、个人信息管理
- **商品模块**：商品CRUD、分类管理、库存管理
- **订单模块**：下单、支付、发货、退款
- **购物车模块**：购物车管理
- **支付模块**：支付接口封装、回调处理
- **物流模块**：物流查询、状态更新
- **营销模块**：优惠券、促销活动、积分

### 4.3 数据库设计概要

#### 4.3.1 核心表结构

**用户相关表**
- `user`：用户表（id、用户名、密码、手机号、邮箱、头像、状态等）
- `user_address`：收货地址表（用户ID、收货人、电话、地址等）
- `user_coupon`：用户优惠券表（用户ID、优惠券ID、使用状态等）

**商品相关表**
- `category`：商品分类表（id、分类名、父分类ID、排序等）
- `product`：商品表（id、商品名、价格、库存、分类ID、状态等）
- `product_image`：商品图片表（商品ID、图片URL、排序等）
- `product_spec`：商品规格表（商品ID、规格名、规格值等）
- `product_comment`：商品评价表（商品ID、用户ID、评分、评论内容等）

**订单相关表**
- `order`：订单表（id、用户ID、订单号、总金额、状态、支付方式等）
- `order_item`：订单明细表（订单ID、商品ID、数量、价格等）
- `order_logistics`：订单物流表（订单ID、物流公司、物流单号、物流信息等）

**购物车表**
- `cart`：购物车表（用户ID、商品ID、数量、规格等）

**营销相关表**
- `coupon`：优惠券表（id、名称、类型、面额、使用条件等）
- `promotion`：促销活动表（id、活动名、类型、规则等）
- `user_points`：用户积分表（用户ID、积分余额、积分记录等）

**系统表**
- `admin`：管理员表（id、用户名、密码、角色等）
- `system_config`：系统配置表（配置键、配置值等）
- `operation_log`：操作日志表（操作人、操作类型、操作内容等）

#### 4.3.2 索引设计
- 用户表：手机号、邮箱建立唯一索引
- 商品表：分类ID、状态建立索引
- 订单表：用户ID、订单号、状态建立索引
- 购物车表：用户ID建立索引

## 七、注意事项

1. **安全性**：
   - 密码加密存储（BCrypt）
   - JWT Token过期机制
   - SQL注入防护
   - XSS攻击防护
   - 接口防刷机制

2. **性能优化**：
   - Redis缓存热点数据
   - 数据库查询优化
   - 图片CDN加速
   - 前端资源压缩

3. **第三方对接**：
   - 所有第三方接口需要做好异常处理
   - 支付回调需要做幂等性处理
   - 敏感配置信息使用配置文件管理，不要硬编码

4. **数据一致性**：
   - 订单支付与库存扣减需要保证事务一致性
   - 使用分布式锁处理并发问题
